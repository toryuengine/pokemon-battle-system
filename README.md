# pokemon-battle-system

第4世代ベースのポケモンバトルシステム（Python）。jsonデータ（種族・技・特性・タイプ相性）を読み込んでポケモンインスタンスを生成し、対戦（技選択→命中判定→ダメージ計算→追加効果）をシミュレーションする。

## 未実装

### ダメージ計算まわり
- 能力ランク補正（`StatStages`）がダメージ計算に未反映（方針として生ステータスを使用）
- 優先度（先制技）が先攻判定に未反映（素早さのみで判定）
- 急所（会心の一撃、当たると通常よりダメージが上がる）

### 状態異常・追加効果の「その後」
- どく・まひ・やけど・ねむり・こおり・こんらんは付与されるだけで、毎ターンのダメージ処理や行動制限（まひで動けない等）は未実装
- 天候（にほんばれ・あまごい・すなあらし・あられ）
- 設置技（ステルスロック・どくびし・まきびし）
- 壁（リフレクター・ひかりのかべ）
- 溜め技・回避ターン（ソーラービーム・あなをほる・そらをとぶ等）
- 反動硬直（はかいこうせん・ハードプラント等）
- 複数回攻撃
- 一撃必殺技
- 変身・コピー系（へんしん・まねっこ等）
- 交代・拘束系（とんぼがえり・まきつく等）

### システム面
- 複数体所持・交代（`Trainer`クラス構想、今は1体対1体固定）
- 効果データの正確性（特にマイナーな技は推測ベースのため要検証）

## 既知の不整合
- わるあがきを暫定的にノーマルタイプ技として実装しているため、本来はタイプ無効化を受けないはずのゴーストタイプ相手に対して0倍（無効）になってしまう
