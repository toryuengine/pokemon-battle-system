# pokemon-battle-system

第4世代ベースのポケモンバトルシステム（Python）。jsonデータ（種族・技・特性・タイプ相性）を読み込んでポケモンインスタンスを生成し、対戦（技選択→命中判定→ダメージ計算→追加効果）をシミュレーションする。

技IDは`src/move/move_XXX.py`の番号で、`data/move.json`のキーと一致する（特性・持ち物も同様）。

## 実装状況

### ✅ 実装済み
それぞれの詳しい仕様は、下の「実装済みの機能の詳細」の同じ名前の節を参照。
- 対戦の基本の流れ（技選択→命中判定→ダメージ計算→追加効果）・急所・タイプ相性・天候・壁・状態異常・設置技
  - やけど状態のポケモンが出す物理技のダメージ半減（こんじょうなら受けない）
  - もうどく（どくどく・どくどくのキバ・どくびし2層・どくどくだま。ターンが進むほどダメージが増える）
  - くろいまなざし（相手を逃げられなくする。まもるを無視し、バトンタッチで交代先に引き継ぐ）
- ぶきよう（持ち物の効果を無くす。くろいてっきゅうは例外、なげつけるは失敗する）
- 技: 全274技（下の「未実装」「本編と違う箇所」に挙げたものを除く）
  - 追加効果を後から実装した技（エアスラッシュ・コメットパンチ等10技）
  - 威力・成否の条件がある技（からげんき・カウンター・げきりん等）
  - 変身・コピー系（まねっこ・ものまね）
  - みがわり・じこあんじ・パワートリック
  - 交代・拘束・特殊なターン管理が必要な技（24技）
  - 毎ターンの回復・吸収、あくび・ほろびのうた・メロメロ・トリックルーム・つぼをつく（8技）
  - まもる・みきり・こらえる、いたみわけ
  - 伝説のポケモンの専用技（ミストボール・ラスターパージ・マグマストーム・にぎりつぶす）
  - グループ1で使われる技（こうそくスピン・しんぴのまもり・とびはねる）
- 技の接触判定と、接触技を受けると発動する特性（ほうし・せいでんき・ゆうばく・メロメロボディ・どくのトゲ・ほのおのからだ）
- 複数体所持・交代（瀕死時の自動交代・とんぼがえり等・手動の交代・おいうち）
- Agentを繋ぐための口（技選択・交代先のポリシー、乱数の差し替え、引き分けの扱い、対戦の経過のイベント）
- バトルファクトリー本体（シングル・オープンレベル。`src/factory/`）：ルールの表・レンタル・相手とネジキ戦・対戦前ヒント・交換・BP・プリント、`FactoryAgent`とランダムAgent（`src/agents/`）、多数回の評価（`src/experiments/`）
- CLI（`src/interface/`）：人間が遊ぶ（AIの助言付きも可）・AIの挑戦を観戦する・AIに自動で多数回挑戦させる、の3つの進め方
- 能力ランク補正（命中率・回避率を含む）、こんらん
- 性別（ポケモンを生成した時点で種族の性別比率からランダムに決定。性別不明の種族にも対応）
- 持ち物: 全56種
- 特性: 全92種のうち84種（ほかに、シングルバトルでは影響の無い8種）
- レベル・個体値・性格・努力値（実数値は種族値から計算。ダメージ計算も攻撃側のレベルを使う）

- 体重は2026-10-09に`data/weight.csv`（PokeAPIのデータ）で足した。第4世代と今の作品で体重が変わった種族は無いはずだが、1体ずつは確かめていない

### ⚠️ 本編（第4世代）と違う・違う可能性がある箇所
274技の効果は基本的に実際のポケモン本編の仕様を参考に実装しているが、対人戦であまり使われない技や、対戦装置本編で採用実績が少なく実効果の記憶があいまいな技は、Claudeの知識ベースでの推測に頼っている箇所がある。

#### 本編と食い違っている可能性が高い箇所
- 技については今は無い（以前ここに挙げていた、だましうち・ふいうち・しんそく・こおりのつぶて・がむしゃら・すてみタックルのクラス名は2026-10-09に直した。下の「既知のバグ」を参照）
- ファクトリーの相手トレーナーは、エンジンのデフォルト（技はランダム、自分からは交代しない、瀕死時は手持ち順）で戦う。本編の相手の思考ルーチンとは違う（`FactoryChallenge(opponent_agent=...)`で任意のAgentにできる）

#### 推測で決めた細かい仕様
- スロースタートの5ターンは、場に出たターンを1ターン目として、ターン終了時に1ずつ数える（ターンの途中で出た場合もそのターンを1ターン目と数える）。いえきで特性を消されている間は数えない（プラチナ・HGSS準拠。いえきは引っ込むまで解けず、出直すとカウントは最初からになるので、途中から再開することはない）
- カウンター系が、複数回攻撃の最後の1回分を返すか・ダメージを与えた相手が交代した後も今の相手に返すか
- ものまね（変身）が身代わりのいる相手に効くか、どの変化技が身代わりを無視するか
- 両者が手動で交代する場合の順番、しっぺがえしが交代してきた相手に威力2倍になるか（今は2倍にならない）
- なげつけるが外れた場合も持ち物を失うか
- ほろびのうたで、ぼうおんの使用者自身がカウントを受けるか
- つぼをつくが、自分にみがわりがいると失敗するか
- かわらわりで、相手がゴーストタイプ（ダメージ無効）のときも壁が壊れるか
- せいでんき・ほのおのからだ等が、特性の持ち主が瀕死になった攻撃でも発動するか（今は発動する）
- ほうしで、どく・まひ・ねむりのどれになるかの確率（今は1/3ずつ）
- 攻撃した側がかたやぶりでも、しめりけでゆうばくが不発になるか（今は不発になる）
- 相手が瀕死で代わりがまだ出ていない（ターンの途中で倒れた）ときに相手に向けた技を出すと、PPを消費して失敗する。だいばくはつも失敗し、自分は瀕死にならない
- はねやすめを、ひこう単タイプのポケモンが使った場合はノーマルタイプとして扱う（第4世代のデータに該当する種族はいない）
- ふいうちは、相手がこのターン選んだ技（`CurrentStatus.selected_move_this_turn`）が攻撃技かで判定する。アンコール等で実際に出す技が変わる場合は見ていない
- ものまね（変身）で体重はコピーしない（くさむすびの威力にだけ効く）
- しんぴのまもりの場では、どくびしでどくにならない。なげつけるで投げられたどくどくだま等の状態異常も防ぐ（相手からの状態異常として扱う）
- こうそくスピンが相手のみがわりに当たった場合も、罠等を取り除く
- あかいいとでメロメロにし返すとき、相手のどんかんで防がれる（メロメロ（技）と同じ判定。かたやぶりも同じように働く）
- めんえき・ふみん・やるき・マイペース・みずのベール・どんかんが、すでにかかっている状態異常を治すタイミングは、持ち物（きのみ）が発動するのと同じ各段階（行動・交代・ターン終了時の各処理の後）で、持ち物より先。なので、めんえきで治るどくにラムのみは使わない。かたやぶりの相手にどく等にされた場合も、その技の後すぐに治る
- 特性・持ち物が発動して判明する場面（上の「Agentを繋ぐための口について」）
  - 状態異常・能力ダウンを特性で防いだときに判明するのは、必ず発動する効果（確率が100%）のときだけ。確率で発動する追加効果を防いだときは何も表示されないものとして、判明しない
  - ふゆうは、第4世代ではじめん技を無効にしたときのメッセージに特性名が出ないが、タイプでは説明できない無効化が見えるので判明する扱い。まきびし等を受けなかったことでは判明しない
  - しぜんかいふくは、第4世代では場を退く時にメッセージが出ないが、手持ちの表示で状態異常が治ったことが分かるので、治った時点で判明する扱い
  - ポイズンヒールは、HPが満タンで回復しなくても、どくのダメージを受けないことが見えるので判明する扱い
  - せんせいのツメは、第4世代では発動してもメッセージが出ないものとして、判明しない。せいしんりょく・たいねつ・ノーてんき・ありじごく・じりょく等も、メッセージが出ないので判明しない
  - よちむで相手の技を1つ見抜く効果は、観測に入れていない（特性が判明するだけ）
- ファクトリー（仕様書に書いていない部分）
  - 第1〜6戦の相手を「今の周」と「1つ前の周」のどちらで作るかは、チーム単位で半々に決める（1体ずつ決めるのかは未確認）
  - 「強いポケモン」の判定に使う「レンタル＋交換」の累計回数は、今から行うレンタルを含めない回数（最初のレンタルでは0）。仕様書6.3の例（3周目開始時に14回なら2体）と合う
  - 強いポケモンが候補6体のどこに来るかは分からないので、候補の並びは混ぜる
  - ネジキ戦の前にも、ほかの対戦と同じ周のヒントを出す。ネジキのチームも、プレイヤーと同じ種族・持ち物を除いて作る
  - 交換で入れた相手の個体は、相手の個体値・性別・特性のまま使う
  - ポケモンの性別・特性は、レンタル候補・相手を作った時点でランダムに決め、以後は変わらない
  - 対戦のターン上限（1000ターン）に達して決着しなかった場合も、引き分けと同じくプレイヤーの負けにする

### 直したもの（2026-10-09）
- **対戦の進行**: 瀕死になった個体の代わりは、ターン終了時の処理が全部終わってから出す（`Battle.process_end_of_turn`）。先攻の攻撃で後攻が瀕死になっても、そのターンのターン終了時の処理（どく・天候ダメージ・天候や壁の残りターン等）が行われる。先攻がだいばくはつ・反動・いのちのたま等で倒れた場合、後攻の相手に向けた技は対象がいなくて失敗する（交代してきた個体には当たらない）。おいうち・設置技で倒れた場合も代わりはターン終了時に出る
- たいねつのやけどダメージが二重に掛かっていた（1/32だけになった）
- ねむりで行動できないターン数を1〜4に（第4世代）
- まもる・みきり・こらえるの連続成功率を1/2ずつ・1/8で下げ止まりに（第4世代）
- 一撃必殺技の命中率を「30＋（自分のレベル−相手のレベル）」に。ランク補正を受けず、相手の方がレベルが高いと必ず失敗する（ノーガードでも）
- こおり: ほのお技を本体に受けると解ける、にほんばれの間はこおりにならない、フレアドライブはこおり状態でも使えて自分のこおりが解ける
- ソーラービームの威力が、雨に加えてすなあらし・あられでも半分になる
- そらをとぶ・ダイビング・あなをほるの最中に当たる技: かみなり・たつまき（威力2倍）がそらをとぶに、うずしお（威力2倍）がダイビングに、じわれがあなをほるに当たる
- 技のデータ: でんげきは（必中・追加効果なし）、ボルテッカー（10%でまひ）、ブレイズキック（急所に当たりやすい）、こらえる（優先度+3）、接触判定（こおりのつぶては非接触、くさむすび・しぼりとる・にぎりつぶすは接触）、はねやすめ（そのターンの間ひこうタイプが無くなる。HPが満タンなら失敗）
- 本編と違っていた技: だましうち（優先度0・必中）、ふいうち（優先度+1。相手が攻撃技を選んでいない・既に行動していれば失敗）、しんそく（優先度+1）、こおりのつぶて（優先度+1）、がむしゃら（相手の残りHPを自分の残りHPと同じにする）
  - クラス名の取り違えも直した: `TakeDown`→`DoubleEdge`（すてみタックル）、`Feint`→`SuckerPunch`（ふいうち）、`SuckerPunch`→`FeintAttack`（だましうち）、`ZapCannon`→`ShockWave`（でんげきは）、`Flail`→`Endeavor`（がむしゃら）、`Flail2`→`Flail`（じたばた）
- ピントレンズのなげつけるの威力を30に
- ダメージ計算を第4世代の式の順番どおりに、補正のたびに切り捨てるようにした（下の「ダメージ計算について」）
- 瀕死の相手に追加効果（状態異常・能力ランクの変化・ひるみ）が付かない（シンクロも瀕死の個体からは発動しない）
- 体重のデータ（`data/weight.csv`）を足し、くさむすびの威力を相手の体重で決める（20〜120）
- じこさいせい・タマゴうみ等の回復技（`("heal", ratio)` の技）が、HPが満タンなら失敗する（2026-10-21。以前は回復量0で成功扱いだった）

## 実装済みの機能の詳細

### ポケモンのデータについて
ポケモンのデータは次のファイルに分かれている。
- `data/pokemon.json`: 種族ごとのタイプ・特性の候補と、4つのセット（持ち物・技4つ・性格ID・努力値）。セットはバリエーション番号（1〜4）と、どの周で使うかを表すグループ（伝説以外は4〜7がバリエーション1〜4、伝説は全セット8）を持つ
- `data/round.json`: オープンレベル（仕様書6.1・8節）のプールの定義
  - `rounds`: 周の番号 → 周の名前と、その周で使うグループの一覧（`groups`）。0〜3（1〜4周目）はその周のバリエーションのグループ（4〜7）だけ、4（5周目以降）はグループ4〜8（全バリエーション＋伝説）
  - `nejiki`: ネジキ戦で使うグループ。`silver`（21戦目）はグループ4（バリエーション1・伝説なし）、`gold`（49戦目）はグループ7と8（バリエーション4＋伝説の全セット）
- `data/pokemon_name.json`: 種族ID → 種族名
- `data/species.json`: 種族ID → 図鑑番号・メスになる確率・伝説かどうか（`pokemon.json`に無い、種族ごとの情報）
- `data/base_stats.json`: 図鑑番号 → 種族名・タイプ（`data/type.json`のID。単タイプなら`type2`は`null`）・種族値（第4世代の値）・体重（kg）。ファクトリーに出てこない種族も含めた全493種。ユーザーが作った`data/base_stats.csv`と`data/weight.csv`から`tools/build_base_stats.py`で作る（CSVを直したら`python tools/build_base_stats.py`で作り直す）。`readpokemondata.load_base_stats_data()`で読める
- `data/weight.csv`: 図鑑番号 → 体重（kg）。PokeAPIのデータ（https://github.com/PokeAPI/pokeapi の`data/v2/csv/pokemon.csv`。図鑑番号1〜493の通常の姿）から作った。くさむすびの威力に使う（`Pokemon.weight`）。ギラティナ（オリジンフォルム）等の別の姿の体重は持たない（種族値も通常の姿だけ）

`readpokemondata.load_pokemon_data()`は、これらをまとめて「種族ごとにセットを並べたリスト」を返す（150種・各4セット）。セットの並びはバリエーション番号の順で、`Pokemon(pokemon_id, indivisual_id)`はこのリストの位置で指定する。周ごとに出てくるセットは`load_round_pool(周)`で`(pokemon_id, indivisual_id)`のリストとして得られる（`round.json`の`groups`に入っているグループのセットを集める。6周目以降は5周目以降と同じプール）。ネジキ戦のセットは`load_nejiki_pool("silver"/"gold")`で得られる。
- 以前は周ごとのファイル（`pokemon_0〜8.json`）に、その周で出てくるセットだけを持っていた。2026-10-07に`pokemon.json`＋`round.json`の形に置き換え、技・持ち物のIDも振り直した（全600セット・各周のセットの中身は名前で比べて変わっていない）。古いファイルは`delete/`に移してある
- 2026-10-08に`round.json`をLv.50向けの積み上げ式（周ごとにグループが増え、銀ネジキ・5周目以降は全セット）から、原作のオープンレベルの割り当てに作り直した
- 実数値は`src/nature.py`の`calc_stats`で、種族値・努力値・性格・個体値・レベルから計算する。`Pokemon(pokemon_id, indivisual_id, level=100, iv=0, rng=None)`で、レベル・個体値（フロンティアのポケモンは全能力が同じ値）を指定できる。省略するとLv.100・個体値0（以前のデータの実数値と同じ条件）
- 性格はデータ上は性格ID（がんばりや=0〜きまぐれ=24）で持ち、`nature.NATURE_NAMES`で性格名にする
- 種族値は`data/base_stats.json`から図鑑番号で引く。読み込み時に、`base_stats.json`と`pokemon.json`で種族名・タイプが一致することを確かめている
  - 以前は`data/species.json`に150種分の種族値を持っていた（伝説以外の136種は`tools/enrich_pokemon_data.py`でPokémon Showdownのデータから第6世代以降の変更を除いたもの、伝説14種は手入力）。`base_stats.csv`の値はこの150種すべてで図鑑番号・種族値・タイプが一致したので、種族値の出どころを`base_stats.json`に一本化した（実数値は変わらない）
  - 以前のデータにあったLv.100・個体値0の実数値と、新しいデータの努力値・性格から計算した実数値が全544セットで一致することを確かめている
- 伝説14種の図鑑番号・メスになる確率は手で入れている
- 性別・特性を決める乱数は`rng`（`random.Random`）を渡せば固定できる

- ゆめくい（112）: ねむっている相手にしか効かない（失敗してもPPは消費する）。与えたダメージの1/2を回復する。判定は技を出す時点の状態で行うので、同じターンに相手が先に目を覚ましていれば失敗する
- ねむる（168）: HPを全回復し、どく・まひ等の状態異常を治してから2ターンねむる（3ターン目に起きて行動する。はやおきなら1ターン）。こんらん等のstatus_condition以外の状態は治らない。HPが満タン・既にねむっている（ねごとで呼び出した場合も含む）・ふみん・にほんばれ中のリーフガードなら、回復もせずに失敗する（PPは消費する）

- げきりん（9）・あばれる（147）: 最初に使ったときに2〜3ターンその技に固定され（PPは最初のターンだけ消費）、最後のターンを終えるとこんらんする（マイペースならこんらんしない）。外れた・まもるで防がれた・タイプや特性で無効にされた場合は、その時点でこんらんせずに固定が解ける（最後のターンでもこんらんしない）。相手が先に瀕死になっていて出せなかったターンは数えず、固定も続く。行動できなかった（まひ・ねむり・ひるみ・こんらんの自傷等）・交代した場合は、こんらんせずに固定が解ける。ねごとで呼び出した場合は固定されない

- ジャイロボール（129）: 威力 = 25 × 相手の素早さ ÷ 自分の素早さ + 1（最大150）。素早さはランク補正・まひ・持ち物・特性を反映した、行動順の判定と同じ値を使う
- おしおき（146）: 威力 = 60 + 20 × 相手の上がっている能力ランクの合計（命中率・回避率も含み、下がっているランクは数えない。最大200）
- きりふだ（252）: 使った後の残りPPで威力が決まる（4以上→40、3→50、2→60、1→80、0→200）。PPは技を出した時点で消費済みなので、プレッシャーで2減った分も反映される

- メタルバースト（214）: 優先度0。このターンに本体が攻撃技（物理・特殊どちらでも）で最後に受けたダメージの1.5倍を与える。相手より先に行動すると失敗する

### 変身・コピー系について
まねっこ（相手が直前に使った技をPP5でコピー）・ものまね（タイプ・実数値〈HP以外〉・技構成〈各PP5〉・特性をコピーして変身）を実装している。
- コピーした技・変身した姿は、交代して手持ちに戻ると元に戻る（`Battle.restore_copied_state`。バトンタッチでも引き継がない）。元の技はインスタンスごと戻すので、まねっこ自身の減ったPPもそのまま残る
- パワートリックで入れ替えた後に変身した場合・変身した後にパワートリックを使った場合も、交代すると入れ替える前の元の実数値に戻る

### みがわり・じこあんじ・パワートリックについて
第4世代仕様で実装した。いずれも状態は`CurrentStatus`（`substitute_hp`・`is_power_trick_active`）に持たせ、交代で場を退くと`Battle.clear_volatile_statuses`で解除し、バトンタッチでは交代先に引き継ぐ。
- みがわり: 最大HPの1/4（端数切り捨て）を払って、そのHPを持つ身代わりを作る。既に身代わりがいる、残りHPが払うHP以下、払うHPが0（最大HP1）なら失敗する
  - ダメージ技は身代わりが受け、身代わりの残りHPを超えた分は本体に届かない。複数回攻撃で途中で壊れた場合、残りの攻撃は本体に当たる。反動・かいがらのすず・いのちのたまは身代わりに与えたダメージで発動する
  - 身代わりが受けた攻撃では、半減実・きあいのタスキ・こらえる・いかりのつぼ・テクスチャー2の記録は発動しない。その攻撃の追加効果（状態異常・能力ランクダウン・ひるみ・はたきおとす・しめつけ・なげつけるの効果・おうじゃのしるし）は、攻撃で身代わりが壊れた場合も含めて本体に届かない
  - 相手に向けた変化技（どくどく・いばる・いたみわけ・いえき・トリック・くろいまなざし・あくむ等）は失敗し、吸収技（ギガドレイン・ドレインパンチ・ゆめくい）も失敗する。ほえる・ちょうはつ・アンコール・かなしばり・いちゃもん・うらみ・ゴーストタイプののろいは身代わりを無視して効く
  - 相手の特性によるランクダウン（いかく）も防ぐ
- じこあんじ: 相手の能力ランク（命中率・回避率を含む）を、そのまま自分にコピーする。まもる・みがわりには防がれない
- パワートリック: 自分の攻撃と防御の実数値を入れ替える（能力ランクは入れ替えない）。もう一度使うと元に戻る。ものまねで変身すると実数値ごと置き換わるので、入れ替えた状態も無くなる

こんらんの自傷・ターン終了時のダメージ（天候・どく・やけど・のろい・しめつけ等）は、身代わりではなく本体が受ける。みらいよちは第4世代仕様で身代わりを無視せず、身代わりが受ける（身代わりの残りHPを超えた分は本体に届かず、きあいのタスキ等も発動しない）。

### 複数体所持・交代について
`Trainer`クラス（`src/trainer.py`）を追加し、手持ち複数体・場に出ているポケモンが瀕死になった時の自動交代（手持ちの中から生きている次の1体を自動選出）に対応した。本編どおり、瀕死になった個体の代わりはターン終了時の処理が全部終わってから出す（`Battle.process_end_of_turn`の最後の`resolve_faints`）。それまでの間、瀕死の個体は行動せず、ターン終了時の処理も受けず、相手がその個体に向けた技は失敗する。あわせて設置技（ステルスロック・まきびし・どくびし）も、この交代の仕組みに乗せて実装済み。とんぼがえりのような「攻撃後に自分から交代する技」も、同じ選出の仕組みで実装済み（交代先の選び方は下記「Agentを繋ぐための口について」）。手動の交代は下記「手動の交代について」を参照。`Battle(pokemon1, pokemon2)`のように単体の`Pokemon`を直接渡した場合は、今まで通り手持ち1体だけの`Trainer`として扱われる（後方互換）。

### 手動の交代について
技を出す代わりに、手持ちの別のポケモンに自分の意思で交代できる。交代するかどうか・誰に交代するかは`Trainer`の`switch_policy`（`(battle, trainer)`を受け取り、交代先の手持ちのインデックスか、交代しないなら`None`を返す関数）で決める。
- `Trainer(party)`のように`switch_policy`を渡さなければ、今まで通り手動では交代しない（瀕死時・とんぼがえり等の自動交代のみ）
- `Trainer(party, random_switch_policy(0.3))`のように渡すと、毎ターン30%の確率で、交代できる手持ちからランダムに1体選んで交代する。自前の判断を書く場合は、`trainer.find_switch_candidates()`で交代先の候補（場に出ていない生存個体のインデックス）を取れる
- 毎ターン、技を選ぶ前に交代するかを決め（`Battle.choose_switch`）、交代は技より先に行う（`Battle.perform_manual_switches`）。両者が交代する場合は素早さが高い方から交代する。交代した側はそのターン技を出さず、交代しなかった側は交代先のポケモンに技を出す
- 交代先が場に出た時の処理（能力ランクのリセット・設置技・特性・持ち物）は、瀕死時の交代と同じ`Battle.switch_in`で行う。設置技で瀕死になれば、ターン終了時に手持ちから次の1体が自動で出る
- 次の状態では交代できない（`Battle.can_switch_out`）: 溜め技の溜め中・げきりん等の固定中・はかいこうせん等の反動で動けないターン、くろいまなざし・しめつけ系の技・ねをはる（`Battle.is_trapped`）、相手のありじごく（地面にいる相手。ひこうタイプ・ふゆう・でんじふゆう中なら交代できる）・じりょく（はがねタイプの相手）
- おいうち（156）: 相手が交代しようとしていれば、交代する前に威力2倍（80）で攻撃する（優先度・素早さに関係なく交代の前に当たる）。おいうちで瀕死になった場合は交代できず、ターン終了時に手持ちから次の1体が自動で出る。瀕死・とんぼがえり・バトンタッチ・ほえるによる交代に対しては発動しない

### Agentを繋ぐための口について
ファクトリーの判断（ターンの行動・交代先）を外から差し替え、同じ対戦を再現できるようにするための仕組み。テストは`tests/test_engine_hooks.py`。
- **技選択**: `Trainer(party, move_policy=...)`。`(battle, trainer, 選べる技のリスト)`を受け取り、その中の1つ（同じインスタンス）を返す関数。溜め技・げきりん・アンコール・こだわり系による固定と、かなしばり・ちょうはつ・いちゃもん・PP切れによる制限は`Battle.select_move`が先に処理するので、ポリシーには本当に選べる技だけが渡る（固定中・わるあがきのときは呼ばれない）。`None`なら今まで通りランダム。リストに無い技を返すと`ValueError`
- **交代先**: `Trainer(party, replacement_policy=...)`。瀕死・とんぼがえり・バトンタッチで次に出す個体を、`(battle, trainer, 候補のインデックスのリスト, 理由)`を受け取って返す関数（理由は`"faint"`/`"u_turn"`/`"baton_pass"`）。`None`なら今まで通り手持ち順で最初の生存個体。候補に無い値を返すと`ValueError`。両者が同時に瀕死になったときは、本編どおり相手の交代先を見ないまま両者が選んでから交代する。ほえる等で強制的に交代させられる場合は、今まで通りランダム
- **乱数**: `Battle(side1, side2, rng=random.Random(seed))`。対戦中の乱数（命中・急所・ダメージの乱数・追加効果・行動順の同速判定・持ち物・特性・ランダムな技選択等）はすべて`battle.rng`から引く。ポケモンの生成（性別・特性）にも同じ`rng`を渡せば、同じシードで全く同じ対戦になる。省略すると`random`モジュールを使う（今までと同じ）
- **勝敗**: `battle.get_winning_trainer(draw_winner=...)`は勝った`Trainer`を返す。同時全滅（引き分け）なら`draw_winner`を返すので、ファクトリーでは相手のトレーナーを渡して引き分けをプレイヤーの負けにする（仕様書10節）。決着していない（ターン上限に達した）ときは`None`。今までの`get_winner()`（場のポケモンを返す）もそのまま使える
- **対戦の経過**: `battle.events`に`BattleEvent(turn, kind, side, data)`が起きた順に積まれる（`src/battlelogic/events.py`に種類と中身の一覧）。種類は登場（`switch_in`）・ターン開始・技（`move`/`move_result`）・行動不能・HP・瀕死・状態異常・持ち物の変化・特性/持ち物の発動（`ability`/`item_activate`）・対戦終了。HP・状態異常・持ち物の変化は、変える処理があちこちにあるため、行動・交代・ターン終了時の各段階の前後の差分から作る（何によって変わったかは持たない）。中身は真の状態なので、Agentに渡す観測はここから見える情報だけを取り出して作る。大量に回すときは`Battle(..., record_events=False)`で記録を止められる（300戦で約3割速くなる）
- **特性・持ち物の発動**: 本編で画面にメッセージが出る（または特性・持ち物でしか説明できない出来事が見える）場面で、特性・持ち物の側から`Battle.reveal_ability`・`reveal_item`を呼び、`ability`（`ability_id`・`is_original`）・`item_activate`（`item_id`）を記録する。倍率が掛かるだけの特性・持ち物（テクニシャン・こだわりハチマキ等）は記録しない。消費・はたきおとす等で持ち物が無くなった・変わったことは、これまでどおり`item`で分かる
  - 特性: いかく・プレッシャー・かたやぶり・すなおこし・ゆきふらし・トレース（トレースと相手の特性の両方）・ダウンロード・スロースタート・よちむ・きけんよち（相手に効果抜群・一撃必殺・だいばくはつ系の技があるときだけ）は場に出た時。ちくでん・ちょすい・かんそうはだ・もらいび・でんきエンジン・ぼうおん・がんじょう・ふゆうは技を無効化した時。ふみん・やるき・めんえき・マイペース・みずのベール・リーフガード（状態異常）、クリアボディ・かいりきバサミ・するどいめ（能力ダウン）は、必ず発動する効果（さいみんじゅつ・いかく等）を防いだ時。ふみん・やるき・めんえき・マイペース・みずのベール・どんかんは、すでにかかっていた状態異常を治した時も。ねんちゃく・きゅうばん・どんかん・しめりけは技を防いだ時。せいでんき・ほうし・どくのトゲ・ほのおのからだ・メロメロボディ・シンクロ・ゆうばく・ヘドロえき・いかりのつぼは発動して効果があった時。かそく・ふくつのこころは素早さが上がった時、あめうけざら・アイスボディ・かんそうはだはHPが変わった時、うるおいボディ・しぜんかいふくは状態異常が治った時、ポイズンヒールはどくのターン終了時、なまけはなまけた時
  - `is_original`は、元の特性（`Pokemon.original_ability_id`）が発動したか。トレース・へんしんでコピーした特性が発動した場合はFalse
  - 持ち物: たべのこし・くろいヘドロ・かいがらのすず（HPが変わった時）・いのちのたま（反動を受けた時）・きあいのハチマキ（耐えた時）・どくどくだま（もうどくになった時）・あかいいと（相手もメロメロになった時）

### バトルファクトリー本体について
仕様書（`Battle factory gen4 rules.md`）のシングル・オープンレベルを再現する。テストは`tests/test_factory_rules.py`（ルールの表）・`tests/test_factory.py`（生成・ヒント・進行）・`tests/test_factory_battle.py`（1戦と観測）。
- **ルールの表**（`factory/rules.py`）: 個体値（6.2）・強いポケモンの数（6.3）・BP（9）・ヒントの種類（7）・ネジキ戦（8）・相手の周（6.4）。周は1始まりの番号（1周目=1）で扱う
- **ポケモン**（`factory/generation.py`）: `FactoryPokemon`（セット・レベル・個体値・性別・特性）を持ち、対戦のたびに`build()`で`Pokemon`を作り直す。勝った後の全回復は作り直すことで行う（HP・PP・状態異常・消費した持ち物・ものまねで覚えた技等が元に戻る）。性別・特性を固定するため、`Pokemon(..., gender=, ability_id=)`を足した
  - レンタル候補6体: 種族・持ち物が全員別。強いポケモンの分は次の周のプール・個体値で作る
  - 相手: 第1〜6戦は今の周か1つ前の周、第7戦は次の周。21戦目・49戦目はネジキ（`round.json`の`nejiki`のプール、個体値12・31）。プレイヤーの手持ちと同じ種族・持ち物は除き、チームの中でも種族・持ち物は重ならない
- **対戦前ヒント**（`factory/hint.py`）: 1周目は3体の名前、2周目は先頭2体の名前、3周目は先発の名前と1番目の技、4周目は先発の1番目の技、5周目以降は最も多いタイプ（複合タイプは両方数え、同数なら第4世代の内部番号の小さい方）
- **進行**（`factory/challenge.py`の`FactoryChallenge`・`factory/state.py`の`FactoryState`）: 周の第1戦の前にレンタル → 相手の生成・ヒント → 並び順 → 対戦 → 勝てば第1〜6戦の後に交換 → 第7戦に勝てば周クリア・BP、ネジキに勝てばプリント。負けたら連勝・累計回数・手持ちを0に戻す（BP・プリントは残る）。`play_challenge()`で負けるまで続け、`play_next()`で1戦（必要ならレンタル、勝てば交換まで）ずつ、`rent()`・`play_battle()`・`offer_trade()`で1段階ずつも進められる。`play_next(on_battle_end=)`に関数を渡すと、対戦の直後（交換を聞く前）にその戦の記録を渡して呼ぶ
- **判断はすべてAgentに聞く**（`agents/base.py`の`FactoryAgent`）: `choose_rentals`（候補6体から3体）・`choose_order`（並び順）・`choose_action`（ターンの行動）・`choose_replacement`（瀕死・とんぼがえり・バトンタッチの交代先）・`choose_trade`（交換するなら自分と相手の位置）。不正な答えは`ValueError`。ファクトリーは`agents`をimportしない
  - ターンの行動は`TurnAction`（`move(技の位置)`か`switch(手持ちの位置)`。わるあがきは`move(None)`）。エンジンは「交代するか」→「どの技か」の順に聞くので、交代を聞かれたときにAgentに1つ選ばせ、技なら技選択のときにそれを返す（`factory/battle_runner.py`の`AgentSide`）。交代できないターンは技だけを、技が固定されていて交代もできないターン（溜め技・げきりん等）は聞かない
  - 選べる技は`Battle.get_selectable_moves`（状態を書き換えずに、アンコール・こだわり系・ちょうはつ等を反映した技の一覧を返す）で作る
- **観測**（`factory/observation.py`）: Agentには`Battle`や相手の`Pokemon`を渡さず、観測だけを渡す
  - レンタル: 候補6体の`FactoryPokemon`（セット・個体値・性別・特性が全部分かる）。並び順: 自分の3体とヒント。交換: 自分の3体と、直前の相手3体の**種族IDだけ**
  - ターン: 自分側は全部（HP・PP・持ち物・特性・実数値・能力ランク・一時的な状態）。相手側は、場に出てきた個体の種族・タイプ・HPの割合・状態異常・能力ランク・見て分かる一時的な状態（こんらん・みがわり等）、使った技、発動して判明した元の特性（`revealed_ability_id`）、持ち物が変わったとき（消費・はたきおとす・トリック等）や消費されずに発動したとき（たべのこし等）に判明した元の持ち物（`revealed_item_id`）だけ。トリックで受け取った持ち物・トレース等でコピーした特性が発動しても、元の持ち物・特性とは数えない。場に出ていない相手は数しか分からない。両方の場の壁・設置技、天候・トリックルームも見える
  - どの観測にも`FactoryContext`（周・周の何戦目か・連勝数・何戦目か・レンタル＋交換の累計回数・ネジキ戦か）が付く
  - 対戦の経過: ターンの観測の`new_events`に、前回の観測から今までに起きた**見える出来事**（`VisibleEvent`）が入る。`Battle.events`から、相手のセットの番号・相手に与えたダメージの実数を除き、相手のHPは割合にしたもの。対戦が終わると、Agentの`on_battle_end`（判断はしない。デフォルトは何もしない）に最後のターンの経過と勝敗が渡る
- **ランダムAgent**（`agents/random_agent.py`）: すべてランダムに選ぶ。`switch_chance`を渡すと交代を選ぶ確率を決められる（省略すると技と交代を区別せず一様に選ぶ）
- **評価**（`experiments/evaluate.py`）: `cd src; python -m experiments.evaluate --agent random --challenges 1000 --seed 0`で、平均連勝数・周ごとのクリア率・ネジキ戦の勝率と、シード・回数・コミットを出す。ファクトリー側とAgent側には別々の乱数を渡し、ファクトリー側はシードと挑戦の番号だけで決まる
  - Agentは`agents/registry.py`に名前で登録し、評価・CLIの両方から同じ名前で選ぶ。見える出来事を観測に足したため、変更前より1割強遅くなった（成績は同じ）
  - 2026-10-20の結果（シード0・10000回）: `random`（行動を一様に選ぶ）は平均連勝数0.49・1周目クリア0.03%、`random-noswitch`（交代しない）は平均連勝数1.06・1周目クリア1.3%。相手もランダムに技を選ぶので1戦の勝率は5割前後になり、交代を多く選ぶ分`random`は弱い

### CLIについて
`src/interface/`。どの進め方も同じ`FactoryChallenge`の上で、判断するAgentだけを差し替える。表示（`print`）はここだけで行い、`factory`は文字列を作らない。テストは`tests/test_interface.py`。
```
cd src
python -m interface.cli play  [--seed N] [--advisor random]            # 人間が遊ぶ
python -m interface.cli watch [--agent random] [--seed N] [--pause]     # AIの挑戦を見る
python -m interface.cli auto  [--agent random] [--challenges N] [--seed N]  # 自動プレイ（experiments.evaluateと同じ）
```
- **人間が遊ぶ**（`interface/human_agent.py`の`HumanAgent`）: レンタル候補・自分の手持ちはセット（持ち物・特性・性格・個体値・実数値・技）を全部見せ、番号で選ぶ。対戦中は観測の`new_events`をメッセージにして見せ（`interface/narrator.py`）、場・両者の場の個体・控えの状態と、選べる行動を並べる。相手については観測にある情報（見えた技・判明した特性と持ち物・HPの割合等）だけを見せる。特性・持ち物が発動したときは`［カビゴン の たべのこし］`のように経過に出す。交換の時は相手の種族だけ。`q`でやめる、`d`で自分の手持ちの詳細。入力・出力は関数で差し替えられる
  - `--advisor`を付けると、判断のたびに、そのAgentが同じ観測から選んだものを「助言」として見せる（選ぶのは人間）
  - `--seed`を省くと毎回違う挑戦になる。使ったシードは最初に表示するので、同じシード・同じ入力なら同じ挑戦をやり直せる
- **観戦**（`interface/spectator.py`の`SpectatorAgent`）: AIの判断をそのまま使い、経過と選んだ行動を表示する。観測も選ぶ行動も変えないので、同じシードなら自動プレイと同じ挑戦になる（テストで確かめている）。`--pause`で1ターンごとにEnterを待つ

### 能力ランク補正について
能力ランク補正（`StatStages`）は本編（第4世代）仕様でダメージ計算・行動順に反映している。
- 攻撃・防御・特攻・特防のランクは、ダメージ計算時に実数値へ段階倍率（基準2）を掛ける。急所に当たった場合は、攻撃側の下降ランクと防御側の上昇ランクを無視する
- 素早さのランクは行動順の判定に反映する（`Battle.get_effective_speed`）。まひ状態の素早さ1/4もここで反映する
- 命中率・回避率のランクは基準3の段階倍率で命中判定に反映する（下記）
- つるぎのまい等、自分自身・場に向けた変化技は、相手が回避状態（あなをほる等）でも成功する

能力変化技の一覧は`docs/move-lists/能力変化技一覧.md`を参照。あわせて以下の技の固有仕様も実装済み。
- はらだいこ: 最大HPの半分を削って攻撃ランクを+6にする（残りHPが半分以下、または既に+6なら失敗）
- おきみやげ: 命中・失敗に関わらず使用者が瀕死になる
- じゅうでん: 特防+1に加え、次のターンの終わりまで、でんき技の威力が2倍になる（でんき技を使うと解除）
- のろい: ゴーストタイプが使うと、自分のHPを半分削って相手をのろい状態にする（毎ターン最大HPの1/4を失う）。それ以外のタイプは攻撃・防御+1、素早さ-1
- たくわえる: 最大3回まで。はきだす・のみこむで、たくわえた回数と防御・特防の上昇分を元に戻す
- いえき: 相手の特性を交代するまで消す（消されている間は「特性なし」として扱う）
- いばる: こんらんを、どく・まひ等の状態異常とは別枠で付与する（状態異常と重複可能）

### ダメージ計算について
`battlelogic/damage.py`の`calculate_damage`は、第4世代のダメージ式の順番どおりに、補正を1つ掛けるたびに切り捨てる。
- ((((Lv×2÷5+2)×威力×攻撃÷50)÷防御)×Mod1＋2)×急所×Mod2×乱数(85〜100)÷100×タイプ一致×タイプ1×タイプ2×Mod3
- Mod1: やけど（物理技の半減）・壁（リフレクター/ひかりのかべ。急所なら無視）・天候（晴れ/雨のほのお/みず、ソーラービームの半減）
- Mod2: いのちのたま・メトロノーム（`BaseItem.get_damage_multiplier_before_random`）
- Mod3: たつじんのおび（`BaseItem.get_damage_multiplier`）・いろめがね・フィルター/ハードロック・半減実
- タイプ相性は相手のタイプ1・タイプ2の倍率を1つずつ掛けて、そのたびに切り捨てる（`type_chart.get_move_effectiveness_factors`）
- 効果がある技のダメージは最低1
- 能力ランク・持ち物（こだわり系・ちからのハチマキ等）・特性（テクニシャン・あついしぼう・もらいび等）の補正は、今まで通り実数値・威力に掛けてから式に入れる（もらいびの位置は未確認。「既知のバグ」の「まだ残っている問題」）

### こんらんについて
こんらんは第4世代仕様で実装している。どく・まひ等の状態異常（`status_condition`）とは別枠（`confusion_turns_remaining`）で管理し、他の状態異常と重複する。
- 混乱したまま行動するのは1〜4ターン（ランダム）。ねむり・こおりで動けないターンは経過しない
- 行動するたびに1/2の確率で自分を攻撃し、そのターンは行動できない（PPは減らない）
- 自傷ダメージは、威力40・タイプなしの物理技で自分自身を攻撃した扱い（`calculate_confusion_damage`）。自分の攻撃・防御の実数値とランク補正を使い、急所・タイプ一致・タイプ相性・天候・壁の影響は受けない
- 交代すると解除される

### 命中率・回避率のランク補正について
`StatStages`に`accuracy`/`evasion`を追加し、命中判定（`Battle.get_effective_hitrate`）に反映した。命中率・回避率は他の能力値（基準2）と異なり基準3の段階倍率（`accuracy_stage_multiplier`）を使う本編仕様に合わせている。対象10技（えんまく・かげぶんしん・だくりゅう・どろばくだん・フラッシュ・ちいさくなる・みやぶる・どろかけ・すなかけ・ミラーショット）はすべて実装済み。みやぶるのみ特殊で、ランクを変更するのではなく相手を「見破った」状態（`CurrentStatus.is_identified`）にし、相手の回避ランクを無視して命中判定するのに加え、ノーマル/かくとう技に対するゴーストタイプの無効化解除（タイプ相性の再計算）にも対応した。見破られた状態は対象が場を退く（交代する）と解除される。

### まもる・みきり・こらえるについて
まもる・みきりは、使用したターンの間だけ相手の技をほぼ全て防ぐ（`CurrentStatus.is_protected`）。ダメージを与える技は常に防がれ、変化技は「相手」に向けた効果（能力ランクダウン・状態異常付与・ひるみ）を持つものだけ防がれる。天候・設置技・壁・自分自身へのバフ（つるぎのまい等）のように場や自分自身に向けた効果は、本編仕様通り防がれない。こらえるは、使用したターンの間だけ瀕死になるはずのダメージをHP1残りに抑える（`CurrentStatus.is_enduring`）。3技とも連続で成功させるたびに次回の成功率が1/2倍になっていき、1/8で下げ止まる第4世代仕様（`protect_stall_counter`、3技で共通の1つのカウンタを使う）を実装しており、これら以外の技を使う・失敗する・交代するとカウンタはリセットされる。

### 交代・拘束・特殊なターン管理が必要な技について
以下の24技を第4世代仕様で実装した。技の使用・交代・ターン終了時にまたがる状態は`CurrentStatus`（ポケモン側）に、みらいよちのように「場」に向けられる状態は`Trainer`側に持たせ、交代で場を退くと`Battle.clear_volatile_statuses`でまとめて解除する。
- 持ち物: はたきおとす（威力20。相手の持ち物をはたき落とし、リサイクルでも戻らない）・トリック（持ち物の入れ替え。入れ替えた後のこだわり系の持ち物は次に使った技に固定される）・なげつける（持ち物ごとの威力で攻撃。技を出した時点で持ち物を手放し、消費した扱いになる）・リサイクル（最後に消費した持ち物を取り戻す）。はたきおとす・トリックはねんちゃくで防がれる。なげつけるで投げたきのみ・しろいハーブは相手が使った扱いになり、どくどくだまはもうどく、おうじゃのしるし・するどいキバは必ずひるませる（持ち物クラスの`on_flung`・`fling_power`）
- 拘束: まきつく・すなじごく・うずしお・マグマストームは2〜5ターン（3/8・3/8・1/8・1/8。ねばりのかぎづめなら5ターン）締め付け、毎ターン終了時に最大HPの1/16を削る。締め付けた側が場を退くと解除される。くろいまなざしは相手を逃げられない状態にする（`Battle.is_trapped`）
- 交代: ほえる（優先度-6、まもるを無視。交代先は手持ちの生存個体からランダム。きゅうばん・ねをはるで防がれる）・バトンタッチ（能力ランク・こんらん・のろい・くろいまなざし・でんじふゆう・いえき・みがわり・パワートリック・ねをはる・アクアリング・やどりぎのタネ・ほろびのうたの状態を引き継いで交代）
- 技の制限: ちょうはつ（3〜5ターン変化技を選べない）・アンコール（4〜8ターン、直前に使った技しか選べない。技を選んだ後にアンコールされた場合は、その技に置き換わる）・かなしばり（4〜7ターン、直前に使った技を選べない）・いちゃもん（同じ技を2回続けて選べない）。選んだ後に制限を受けた技は失敗し、PPも減らない。選べる技が無ければわるあがきになる
- PP: うらみ（相手が直前に使った技のPPを4減らす）・おんねん（次に行動するまでに相手の攻撃で瀕死になると、その技のPPを0にする）
- みちづれ: 次に行動しようとするまでに相手の攻撃で瀕死になると、相手も瀕死にする
- ねごと: ねむっている間だけ使え（ねむりの残りターンは通常通り減る）、自分の他の技からランダムに1つ選んで使う。呼び出した技のPPは減らない。溜め技・きあいパンチ・ねごと自身は呼び出せない
- はきだす・のみこむ: たくわえた回数（1〜3）に応じて、はきだすは威力100・200・300、のみこむは最大HPの1/4・1/2・全回復。使うと、たくわえた回数と、たくわえるで実際に上がった防御・特防のランクを元に戻す。たくわえていなければ失敗する
- でんじふゆう: 5ターンの間、じめんのダメージ技・まきびし・どくびしを受けない（くろいてっきゅうを持っていると無効）
- あくむ: ねむっている相手にだけ効き、ねむっている間毎ターン終了時に最大HPの1/4を削る
- みらいよち: 使ったターンを含めて3回目のターン終了時に、その時点で相手の場に出ている個体を攻撃する。第4世代仕様で、ダメージは使った時点の能力で計算し（タイプなし扱いでタイプ相性・タイプ一致の影響を受けず、急所に当たらない）、命中判定は攻撃する時に行う。まもるでは防げない（使ったターン・攻撃が来るターンのどちらでも）が、身代わりは無視せず身代わりが受ける
- おいうち: 手動で交代しようとする相手に、交代の前に威力2倍で攻撃する（上記「手動の交代について」）

### 毎ターンの回復・吸収、あくび・ほろびのうた・メロメロ・トリックルーム・つぼをつくについて
以下の8技を第4世代仕様で実装した。ポケモンにかかる状態は`CurrentStatus`（`is_ingrained`・`has_aqua_ring`・`is_seeded`・`yawn_turns_remaining`・`perish_turns_remaining`・`infatuated_by`）に、トリックルームは場全体の状態として`Battle.trick_room_turns_remaining`に持たせる。いずれも交代で場を退くと`Battle.clear_volatile_statuses`で解除する。
- ねをはる: 毎ターン終了時に最大HPの1/16を回復する。根を張っている間は自分の意思で交代できず（`Battle.is_trapped`）、ほえるも効かない。地面にいる扱いになり、ひこうタイプ・ふゆうでもじめん技・まきびし・どくびしを受ける（`Pokemon.is_forced_grounded`。でんじふゆうは失敗する）。バトンタッチで引き継ぐ
- アクアリング: 毎ターン終了時に最大HPの1/16を回復する。交代は制限されない。バトンタッチで引き継ぐ
- やどりぎのタネ: 命中率90。毎ターン終了時に、植えられた側が最大HPの1/8（残りHPが上限）を失い、同じ量だけ相手の場のポケモンが回復する（種を植えた個体が交代していれば、交代先が回復する）。くさタイプ・既に植えられている相手には失敗し、みがわり・まもるで防がれる。植えられた側のヘドロえきは、回復する代わりにダメージを与える。植えられた側が交代すると解除され、バトンタッチでは引き継ぐ
- ねをはる・アクアリング・やどりぎのタネの回復量は、おおきなねっこで1.3倍になる。ターン終了時の処理は、みらいよちの後・どく等のダメージの前に、アクアリング→ねをはる→やどりぎのタネの順で行う
- あくび: 相手をねむけ状態にし、次のターンの終わりにねむらせる。相手が既に状態異常・ねむけ状態、ふみん（かたやぶりなら無視）なら失敗し、みがわり・まもるで防がれる。ねむけの間に別の状態異常になると眠らない。交代すると解除され、バトンタッチでは引き継がない
- ほろびのうた: 使った本人を含む場の全員に、ほろびのカウントを付ける。使ったターンの終わりにカウント3になり、以降毎ターン1ずつ減って、カウント0になったターンの終わりに瀕死になる（使ったターンを含めて4回目のターン終了時）。既にカウントがある個体はカウントし直さない。まもる・みがわりに防がれず、使った本人以外はぼうおんで防げる。交代すると解除され、バトンタッチではカウントを引き継ぐ
- メロメロ: 性別が違う相手をメロメロ状態にし、行動するたびに1/2の確率で動けなくする（こんらんの判定の後、まひの判定の前）。どちらかが性別不明、同じ性別、既にメロメロ状態、どんかん（かたやぶりなら無視）なら失敗し、みがわり・まもるで防がれる。使った側・受けた側のどちらかが場を退くと解除され、バトンタッチでは引き継がない
- トリックルーム: 優先度-7。使ったターンを含めて5ターンの間、同じ優先度の中では素早さの遅い方が先に行動する。優先度の違い・せんせいのツメは今まで通り効く。効果中にもう一度使うと解除される
- つぼをつく: 攻撃・防御・特攻・特防・素早さ・命中率・回避率のうち、+6でないものからランダムに1つ選んでランクを+2する。全て+6なら失敗する。第4世代仕様で、自分にみがわりがいると失敗する

### こうそくスピン・しんぴのまもり・とびはねるについて
グループ1のセットで使われる技として、2026-10-20に第4世代仕様で足した（技ID 271〜273）。
- こうそくスピン（271）: ノーマル・物理・威力20・命中100・接触。当たると、自分にかかっているしめつけ系の技・やどりぎのタネと、自分の場のまきびし・どくびし・ステルスロックを取り除く（`Battle.perform_rapid_spin`）。ゴーストタイプには当たらないので取り除けない。第4世代なので素早さは上がらない
- しんぴのまもり（272）: ノーマル・変化。使ったターンを含めて5ターン、自分の場のポケモンが相手から状態異常・こんらんにされなくなる（`Trainer.safeguard_turns_remaining`。交代してきた個体も守られる）。効果中に使うと失敗する。防ぐのは相手の技・なげつける・シンクロ・あくび（ねむけ状態にならない）・どくびしと、どくどくだま（第4世代仕様）。せいでんき等の接触技を受けて発動する特性（第4世代では防げない）、ねむる・げきりんの後のこんらん・既にかかっていたねむけは防がない
- とびはねる（273）: ひこう・物理・威力85・命中85・接触。そらをとぶと同じく1ターン目に跳び上がって回避状態になり、2ターン目に攻撃する。30%で相手をまひにする。上空にいる間も、かみなり・たつまき（威力2倍）・スカイアッパーは当たる

### いたみわけについて
いたみわけは、自分と相手の残りHPを足し算し、その半分（端数切り捨て）をお互いの残りHPにする（`Battle.perform_pain_split`）。分け合った値が最大HPを超える側は、最大HPまでしか回復しない。相手のHPを直接書き換える技のため、まもる・みきりで防がれる。

### 持ち物について
`data/item.json`の全56種の持ち物の効果を、第4世代仕様で実装した。きのみ・きあいのタスキ・パワフルハーブ・しろいハーブのように使うとなくなる持ち物は、消費すると`Pokemon.item`が`None`になり、消費した持ち物は`Pokemon.consumed_item`に記録する（リサイクルの実装用）。

持ち物は`src/item/`にクラスとして実装している。
- `base_item.py`の`BaseItem`が、効果を発揮するタイミングごとのフック（`get_power_multiplier`・`on_after_damage`・`activate`・`on_end_of_turn`等）を「何もしない」デフォルトで持ち、各持ち物は必要なフックだけを上書きする。`Battle`・ダメージ計算は持ち物の種類で分岐せず、`pokemon.held_item`（持ち物が無ければ効果なしの`NO_ITEM`）のフックを呼ぶだけ
- 半減実・ピンチ実・天候を伸ばす岩のように効果が同じでパラメータだけ違う持ち物は、1つのクラス（`ResistBerry`等）を`itemfactory.py`でパラメータを変えて使い回す
- 持ち物IDとクラスの対応は`itemfactory.py`にまとめており、`Pokemon`生成時に`create_item`でインスタンスを作る
- 持ち物のインスタンスは状態を持たない（トリック・リサイクル等でそのまま受け渡せるようにするため）。メトロノームの連続使用回数のような対戦中の値は`Pokemon.current_status`側に持たせる
- 持ち物を追加するときは、`src/item/`の該当する分類のファイルにクラスを追加し、`itemfactory.py`に登録する
- ダメージ補正: ちからのハチマキ・ものしりメガネ（1.1倍）、しんぴのしずく・さざなみのおこう（みず技1.2倍）は技の威力に、こだわりハチマキ・こだわりメガネ（1.5倍）・ふといホネ（カラカラ・ガラガラのみ2倍）は攻撃・特攻の実数値に、いのちのたま（1.3倍）・たつじんのおび（効果抜群のとき1.2倍）・メトロノーム（同じ技を連続で使い続けると1ターンごとに+10%、最大2倍。溜め技は溜めターンも1ターンとして数える）は最終ダメージに掛かる
- 半減実（オッカ・イトケ・リンド・ヤチェ・シュカ・バコウ・カシブ・ヨプ・ソクノ・ウタン・ナモ・ヨロギ）: 対応タイプの効果抜群の技のダメージを半分にして消費する。複数回攻撃なら最初の1発だけ
- 急所: ピントレンズ・するどいツメで急所ランク+1。急所の発生率は急所ランクで決まる（0:1/16、1:1/8、2:1/4、3:1/3、4以上:1/2）
- 命中: こうかくレンズ1.1倍、フォーカスレンズは相手がこのターン既に行動していれば1.2倍、ひかりのこな・のんきのおこうは持ち主に向けた技の命中率0.9倍
- 行動順: こだわりスカーフで素早さ1.5倍、くろいてっきゅうで素早さ1/2。せんせいのツメは同じ優先度の中で20%の確率で先に行動する（両者とも発動した場合は素早さで比べる）
- こだわり系: こだわりハチマキ・こだわりメガネ・こだわりスカーフを持っていると、最初に出した技しか選べなくなる（その技のPPが尽きたらわるあがき）。交代する・はたきおとす等で持ち物を失う・ぶきようで持ち物の効果が無くなると解除される
- 瀕死を耐える: きあいのタスキはHP満タンから瀕死になる攻撃をHP1で耐えて消費する。きあいのハチマキは10%の確率でHP1で耐える（消費しない）。こらえるが優先される
- 攻撃後: かいがらのすずは与えたダメージの1/8を回復、いのちのたまは最大HPの1/10を失う、おうじゃのしるし・するどいキバはひるみ効果を持たないダメージ技に10%のひるみ効果を付ける（とんぼがえりで交代する前に発動する）
- きのみ（HP）: オボンのみはHP1/2以下で最大HPの1/4回復、チイラ・ヤタピ・カムラのみはHP1/4以下で攻撃・特攻・素早さ+1
- きのみ（状態異常）: ラムのみ（状態異常・こんらん）、クラボのみ（まひ）、カゴのみ（ねむり）、キーのみ（こんらん）。しろいハーブは下がった能力ランクを全て0に戻す。これらとHPのきのみは、各ポケモンの行動の後・ターン終了時の処理の後・交代で場に出た後に発動を判定する
- ターン終了時: たべのこしは1/16回復、くろいヘドロはどくタイプなら1/16回復・それ以外は1/8ダメージ。どくどくだまはターンの最後にもうどく状態にする
- 場の効果の延長: あついいわ・しめったいわ・つめたいいわで対応する天候が8ターン、ひかりのねんどでリフレクター・ひかりのかべが8ターン続く
- その他: おおきなねっこで吸収技の回復量1.3倍。パワフルハーブで溜め技の溜めターンを1回だけ省略する。くろいてっきゅうを持つひこうタイプは、じめん技をひこうタイプを除いた相性で受け、まきびし・どくびしも受ける
- ねばりのかぎづめ: しめつけ系の技（まきつく・うずしお・すなじごく・マグマストーム）が必ず5ターン続く
- あかいいと: 持ち主がメロメロ状態になると、メロメロにした相手もメロメロ状態にする（消費しない。メロメロ（技）・メロメロボディのどちらでも発動し、相手がどんかんなら防がれる）。`BaseItem.on_infatuated`

あわせて、後攻側の技で先攻側がひるんだ場合に、そのひるみが次のターンまで持ち越されて行動できなくなっていた不具合を修正した（ひるみは毎ターン開始時に解除する）。

### もうどくについて
第4世代仕様。もうどくは`status_condition`を`"poison"`のまま、`CurrentStatus.toxic_counter`（0なら通常のどく、1以上ならもうどく）で区別する。どく状態を判定する処理（めんえき・からげんき・ポイズンヒール・きのみ・しぜんかいふく等）は、どくともうどくを同じに扱う。
- もうどくになる: どくどく（41）・どくどくのキバ（129、30%）・どくびし2層（1層なら通常のどく）・どくどくだま（ターンの最後、なげつけるで投げつけられた場合も）。技の追加効果では、状態異常の名前に`"toxic"`を指定する（`Battle.try_apply_status`）
- ターン終了時に最大HPの(カウンタ)/16を失い、カウンタが1増える（1/16→2/16→3/16…、15/16で頭打ち）。ポイズンヒールでダメージの代わりに回復したターンもカウンタは増える
- 交代すると、もうどくのままカウンタが1に戻る。状態異常が治るとカウンタも0に戻る
- シンクロは、もうどくにされた場合は相手をもうどくにする

### くろいまなざしについて
第4世代仕様。くろいまなざし（199）を受けた相手は`CurrentStatus.trapped_by`に使用者が記録され、逃げられない状態になる（`Battle.is_trapped`）。
- 逃げられない間は手動で交代できない（`Battle.can_switch_out`）。とんぼがえり・バトンタッチ・ほえるによる交代は、本編同様に防げない
- 既に逃げられない状態の相手には失敗する。みがわりには防がれるが、まもる・みきりは無視する（`bypasses_protect`）
- 使用者が場を退くと相手は解放される。ただしバトンタッチで退いた場合は、第2〜4世代仕様で交代先が引き続き相手を逃げられなくする（第5世代以降は解放される）
- 逃げられない側がバトンタッチすると、交代先も逃げられないままになる
- ゴーストタイプも逃げられなくなる（ゴーストタイプが逃げられるのは第6世代以降）。きれいなぬけがら・マジックコートはデータに無いため未対応

### ぶきようについて
第4世代仕様。ぶきよう（40）のポケモンは、持っている持ち物の効果が無くなる。
- `Pokemon.held_item`（`Battle`・ダメージ計算が持ち物のフックを呼ぶ唯一の入口）が、ぶきようなら効果なしの`NO_ITEM`を返す（`Pokemon.is_item_disabled`）。そのため、たべのこし・こだわり系・いのちのたま・きのみ・どくどくだま・きあいのタスキ等、全ての持ち物の効果が働かない。きのみも食べない（消費しない）
- くろいてっきゅうは例外で、ぶきようでも素早さ1/2・地面にいる扱いの効果が残る（`BaseItem.ignores_klutz`）
- なげつけるは失敗する（持ち物は手放さない）
- 持ち物そのものは持っているので、トリック・はたきおとす・むしくい・ついばむ・リサイクルは普通に働く（トリックでこだわり系の持ち物を相手に渡す、等）
- こだわり系の持ち物で技が固定された後にぶきようを得た場合（ものまね等）は、固定が解除される
- いえきで特性を消されている間は、持ち物の効果が戻る
- ものまね・トレースでぶきようを得た場合も、その時点から持ち物の効果が無くなる

### 技の接触判定について
技ごとに`makes_contact`（`BaseMove`のデフォルトは`False`）を持ち、接触技のクラスで`True`に上書きしている。第4世代仕様で、接触技は次のとおり。
- 物理技のうち、下の17技を除く全て（95技）と、わるあがき
  - 非接触の物理技: タネばくだん・じしん・いわなだれ・ストーンエッジ・ダストシュート・すなじごく・じわれ・ボーンラッシュ・サイコカッター・だいばくはつ・なげつける・こうげきしれい・はっぱカッター・ゴッドバード・メタルバースト・マグネットボム・がんせきほう
- 特殊技・変化技には接触技が無い
- 144（クラス名`Feint`）・184（クラス名`SuckerPunch`）は、データ上の名前（ふいうち・だましうち）に合わせてどちらも接触技にしている

接触技で本体にダメージを与えるたびに、受けた側の特性の`on_contact_received`を呼ぶ（`Battle._resolve_move_hit`）。
- 複数回攻撃では1回ごとに判定する
- みがわりが受けた攻撃、外れた・まもるで防がれた・特性やタイプ相性で無効化された攻撃では発動しない
- 攻撃した側がかたやぶりでも発動する。いえきで特性を消されていれば発動しない
- 攻撃した側にみがわりがいても、しんぴのまもりでも防げない（`try_apply_status`の`bypass_substitute`・`bypass_safeguard`。しんぴのまもりで防げるようになったのは第5世代から）
- 状態異常のタイプ・特性による無効（どく・はがねタイプのどく、めんえき等）は通常どおり働く。うつした状態異常はシンクロでうつし返される

| 特性 | 効果 |
|---|---|
| ほうし | 30%で相手をどく・まひ・ねむりのどれか（1/3ずつ）にする。第4世代なので、くさタイプにも効く |
| せいでんき | 30%で相手をまひにする。第4世代なので、でんきタイプもまひになる |
| どくのトゲ | 30%で相手をどくにする |
| ほのおのからだ | 30%で相手をやけどにする |
| メロメロボディ | 30%で相手をメロメロにする。性別の条件・どんかんで防がれる点はメロメロ（技）と同じ |
| ゆうばく | 接触技で瀕死にされると、相手に相手の最大HPの1/4のダメージを与える。場（自分・相手のどちらか）にしめりけのポケモンがいると発動しない |

- ゆうばくのダメージは、攻撃した側がマジックガードなら受けない
- ゆうばくで攻撃した側が瀕死になったら、複数回攻撃の残りは出さない。ドレインパンチ等の吸収技でも回復しない（みちづれで瀕死になった場合も同じ）

### 性別について
`data/species.json`の各種族に`"female_rate"`（メスになる確率）を持たせ、`Pokemon`を生成した時点で性別をランダムに決めて`Pokemon.gender`（`"male"`/`"female"`、性別不明なら`None`）に入れる。比率は第4世代の本編に合わせている。

- `"female_rate"`の値: `0.0`（オスのみ。ケンタロス・ニドキング・エルレイド）、`0.125`（御三家・イーブイの進化系・化石ポケモン・ルカリオ・トゲキッス・カビゴン等）、`0.25`（カイリキー・フーディン・ハリテヤマ・ウインディ・エレキブル・ブーバーン）、`0.5`（大半の種族）、`0.75`（キュウコン・グランブル）、`1.0`（メスのみ。ハピナス・ミルタンク・ガルーラ・ルージュラ・ニドクイン・ユキメノコ・ビークイン）
- 性別不明の種族は`"female_rate": null`にしている（マルマイン・スターミー・ポリゴン2・ポリゴンZ・ネンドール・ドータクン・ジバコイル・メタグロスの8種）。これらは常に`gender`が`None`になる
- 個体データ（`"indivisual"`の各要素）に`"gender": "male"`/`"female"`/`null`を書くと、抽選せずにその性別で固定できる（テスト用など）
- `src/main.py`は対戦ごとに`Pokemon`を作り直すので、性別も対戦ごとに抽選し直される
- 性別を使う効果: メロメロ・メロメロボディ（性別が違う相手にだけ効く。どちらかが性別不明なら失敗）、とうそうしん（下の「特性について」を参照）

### 特性について
特性は技と同じく1特性1クラスで保持する（`src/ability/`）。`BaseAbility`（`base_ability.py`）が対戦の各場面で呼ばれるフック（場に出た時・ターン終了時・技を受ける直前・ダメージ計算の各倍率など）を「何もしない」デフォルトで持ち、`ability_000.py`〜`ability_091.py`の各特性クラスが必要なフックだけを上書きする。複数の特性で共通する型（ピンチで威力1.5倍・タイプ吸収・状態異常の無効化・天候で素早さ2倍など）は`shared.py`にまとめ、`abilityfactory.create_ability(id)`でIDからインスタンスを作る。`Pokemon.ability`は特性IDではなく、このインスタンスを持つ。もらいびの発動済みフラグやなまけの行動ターンのように特性ごとの状態はインスタンスに持たせ、場に出るたびにリセットする。

`Battle`は特性を`get_ability`（いえきで消されていれば「特性なし」を返す）と`get_target_ability`（攻撃側がかたやぶりなら、受ける側の`is_breakable`な特性を無視する）で取得して使う。`data/ability.json`の全92特性を第4世代仕様で次のように扱っている。

- 実装済み（84種）
  - 場に出た時: いかく・トレース（場を退くと元に戻る）・ダウンロード・すなおこし・ゆきふらし（第4世代仕様で天候がターン経過で終わらない）。両者が同時に瀕死になった場合は、両者の交代が済んでから素早さ順に発動する
  - 技の無効化: ちくでん・ちょすい（1/4回復）・でんきエンジン（素早さ+1）・もらいび（以後ほのお技1.5倍）・かんそうはだ・ふゆう（まきびし・どくびしも無効、くろいてっきゅう・ねをはるで解除）・がんじょう（第4世代なので一撃必殺技の無効化のみ）・ぼうおん
  - 威力・実数値・ダメージ: しんりょく・もうか・げきりゅう・むしのしらせ・テクニシャン・ヨガパワー・こんじょう（やけどによる物理技のダメージ半減も受けない）・はりきり・とうそうしん（同じ性別の相手への威力1.25倍・違う性別なら0.75倍・どちらかが性別不明なら補正なし）・ふしぎなうろこ・あついしぼう・たいねつ・てきおうりょく・いろめがね・フィルター・ハードロック・スナイパー
  - 急所: きょううん・カブトアーマー・シェルアーマー・いかりのつぼ
  - 命中: ノーガード（あなをほる等で隠れている相手にも当たる）・はりきり・すながくれ・ゆきがくれ
  - 素早さ: すいすい・ようりょくそ・はやあし（まひの素早さ低下も無視）・かるわざ・かそく
  - 状態異常: めんえき・ふみん・やるき（ふみんと同じく、ねむり状態にならない）・マイペース・みずのベール・どんかん（メロメロ状態にならない）（以上の6つは、トレース・ものまね（変身）で得た時やかたやぶりの相手に状態異常にされた時など、すでにかかっていればすぐに治す。`BaseAbility.on_update`）・リーフガード・シンクロ・しぜんかいふく・うるおいボディ・ポイズンヒール・はやおき
  - 能力ランク: クリアボディ・かいりきバサミ・するどいめ（相手による低下のみ防ぐ。自分の技による低下は防がない）・ふくつのこころ
  - 交代・持ち物: ぶきよう（持ち物の効果が無くなる。上の「ぶきようについて」を参照）・ねんちゃく（はたきおとす・トリックで持ち物を奪われない）・きゅうばん（ほえるで交代させられない）・ありじごく・じりょく（相手を手動で交代できなくする）
  - その他: せいしんりょく・いしあたま・ヘドロえき・プレッシャー・てんのめぐみ・くいしんぼう・きもったま・かたやぶり・ノーてんき・なまけ・スロースタート（場に出てから5ターン、攻撃（物理技）と素早さが半分）・あめうけざら・アイスボディ・しめりけ（だいばくはつを失敗させ、ゆうばくを不発にする）
  - マジックガード: 技による攻撃以外のダメージを受けない（`Battle.apply_indirect_damage`）。防ぐのは、どく・やけど・のろい・あくむ・しめつけ・やどりぎのタネ（相手も回復しない）・すなあらし/あられ・まきびし・ステルスロック・反動技の反動・いのちのたま・くろいヘドロ・ゆうばく・ヘドロえき。わるあがきの反動・こんらんの自傷・自分で払うHP（はらだいこ・みがわり・ゴーストタイプののろい）は防がない。第4世代だけの仕様として、まひで動けなくなることが無く（素早さは下がる）、どくびしでどくにならない
  - 接触技を受けた時: ほうし・せいでんき・どくのトゲ・ほのおのからだ・メロメロボディ・ゆうばく（上の「技の接触判定について」を参照）
- 第4世代のシングルバトルでは対戦結果に影響しない（8種、`NoBattleEffectAbility`）: ひらいしん・よびみず（ダブルバトル専用）・はっこう・あくしゅう・ものひろい・にげあし・よちむ・きけんよち
