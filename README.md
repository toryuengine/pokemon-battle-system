# pokemon-battle-system

第4世代ベースのポケモンバトルシステム（Python）。jsonデータ（種族・技・特性・タイプ相性）を読み込んでポケモンインスタンスを生成し、対戦（技選択→命中判定→ダメージ計算→追加効果）をシミュレーションする。

## 未実装

いずれも「場の状態」や「パーティ構造」など、既存の1対1固定・技単体のデータ構造では表現できない新しい仕組みが必要なもの。

- 壁（リフレクター・ひかりのかべ）
- 変身・コピー系（へんしん・まねっこ等）
- とんぼがえり等、攻撃後に自分から交代する技（拘束技のまきつく等も含む）
- 効果データの正確性: 267技の効果は基本的に実際のポケモン本編の仕様を参考に実装しているが、対人戦であまり使われない技や、対戦装置本編で採用実績が少なく実効果の記憶があいまいな技は、Claudeの知識ベースでの推測に頼っている箇所がある。特に`move_192.py`（ピヨピヨパンチ）、`move_228.py`（じたばた）、`move_263.py`・`move_264.py`（テクスチャー2・タマゴうみ、実在の技か不明瞭）は要確認

## 複数体所持・交代について
`Trainer`クラス（`src/trainer.py`）を追加し、手持ち複数体・場に出ているポケモンが瀕死になった時の自動交代（手持ちの中から生きている次の1体を自動選出）に対応した。あわせて設置技（ステルスロック・まきびし・どくびし）も、この交代の仕組みに乗せて実装済み。ただし「プレイヤーが戦略的にどのタイミングで手動で交代するか」という判断は無く、瀕死になった時の自動交代のみ。`Battle(pokemon1, pokemon2)`のように単体の`Pokemon`を直接渡した場合は、今まで通り手持ち1体だけの`Trainer`として扱われる（後方互換）。

能力ランク補正（`StatStages`）は方針として意図的にダメージ計算へ反映していない（生ステータスを使用する）。
