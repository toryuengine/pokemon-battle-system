### 目的
CLAUDE.md「やること」C の残り「観測に、特性・持ち物が発動して判明したこと（いかく・たべのこし等）を足す」を実装する。これまで相手の持ち物は「持ち物が変わったとき（消費・はたきおとす・トリック等）」にしか判明せず、特性はまったく観測に入っていなかった。セット推測（ロードマップ6節の2）の前に要る。

### 実施内容
- 全92特性と持ち物のフックを読み、第4世代で「画面にメッセージが出る／特性・持ち物でしか説明できない出来事が見える」場面を洗い出した
- 対戦エンジンにイベントを2種類追加した（`battlelogic/events.py` に説明あり）
  - `ability`：party_index・ability_id・is_original（元の特性か。トレース・へんしんでコピーした特性ならFalse）
  - `item_activate`：party_index・item_id（消費されずに発動した持ち物）
- `Battle` に `locate`（個体の側と手持ちの位置）・`reveal_ability`・`reveal_item`・`is_status_immune_by_type`・`reveal_status_immunity_ability` を追加。`record_events=False` のときは何も記録しない
- `Pokemon.original_ability_id` を追加（is_original の判定用）
- 特性側の発動箇所に `reveal_ability` を入れた
  - 場に出た時：いかく・プレッシャー・かたやぶり（新しい共通クラス `AnnouncedOnSwitchInAbility`）・すなおこし・ゆきふらし・トレース（トレースと相手の特性の両方）・ダウンロード・スロースタート・よちむ・きけんよち（相手に効果抜群・一撃必殺・だいばくはつ系の技があるときだけ）
  - 技の無効化：タイプ吸収系（ちくでん・ちょすい・かんそうはだ・もらいび・でんきエンジン）・ぼうおん・がんじょう・ふゆう
  - 防いだ時（battle.py 側）：状態異常・能力ダウンを防ぐ特性は確率100%の効果のときだけ、ねんちゃく・きゅうばん・どんかん・しめりけ・ヘドロえき
  - 発動して効果があった時：接触で状態異常にする特性・メロメロボディ・シンクロ・ゆうばく・いかりのつぼ・かそく・ふくつのこころ・天候で回復する特性・うるおいボディ・しぜんかいふく・ポイズンヒール・なまけ
- 持ち物側に `reveal_item` を入れた：たべのこし・くろいヘドロ・かいがらのすず（HPが変わった時だけ）・いのちのたま（反動を受けた時）・きあいのハチマキ・どくどくだま・あかいいと
- 観測：`OpponentPokemonView.revealed_ability_id` を追加。`OpponentKnowledge` で `ability`（is_original のものだけ）と `item_activate`（持ち物が一度も変わっていないときだけ）を元の特性・持ち物として記録するようにした。ついでに、トリックで受け取った持ち物が後で消費されると元の持ち物と誤って記録される既存の問題も、`item_changed` フラグで直した
- CLI：状態表示に「特性: 〜」を追加し、経過に `［カビゴン の たべのこし］` の形で出すようにした
- テスト：`tests/test_reveal.py`（13件）を新規作成。`tests/test_factory_battle.py` の観測チェックに「判明した特性は真の特性と一致する」と「30戦で特性が1つ以上判明する」を追加
- 400戦を回して、どの特性・持ち物がどれくらい判明するかを確認した（たべのこし828回・プレッシャー248回など。トレースでコピーされた相手の特性も出ている）
- README（Agentを繋ぐための口・観測・CLI・推測で決めた細かい仕様・やることリスト）と CLAUDE.md（やること C に ✅）を更新した
