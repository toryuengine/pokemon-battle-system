### 目的
README の「効果はあるが、成否の条件が抜けている技」にあった、ゆめくい（112）を直す。
- ねむっている相手にしか効かないようにする（これまでは、起きている相手にも当たって回復していた）

### 実施内容
- 調査
  - `move_112.py` の `DreamEater` は `effects = [('drain', 0.5)]` だけで、成否の判定が無かった。
  - 技の成否は `BaseMove.try_execute` で判定できる（`battle.py` の `_resolve_move_hit` から、まもる・特性・タイプ相性による無効判定の後、みがわり・命中判定の前に呼ばれ、PPは消費済み）。
  - ねむり状態は `current_status.status_condition == "sleep"` で判定できる（あくむ・ねごとと同じ）。
- 実装
  - `DreamEater.try_execute` を追加し、相手がねむっているときだけ成功するようにした。
  - 判定は技を出す時点の状態で行うので、同じターンに相手が先に行動して目を覚ましていれば失敗する。
  - ねむっている相手がみがわりを出している場合は、これまでどおり吸収技のみがわり判定で失敗する。
  - README：未実装リストから削除し、「威力・成否の条件がある技について」に仕様を追記した。
