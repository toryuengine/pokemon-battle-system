### 目的
README の未実装項目「タイプによる状態異常の無効化」を実装する。
- どく・はがねタイプはどく（もうどく含む）にならない
- ほのおタイプはやけどにならない
- こおりタイプはこおりにならない
- でんじははじめんタイプに効かない

### 実施内容
- 調査
  - `Battle.can_receive_status` は特性の `can_receive_status` を呼ぶだけで、タイプを見ていなかった。
  - 状態異常は `try_apply_status`（技の追加効果・シンクロ・あくび・なげつける等）か、`can_receive_status` を通してから呼ぶ `inflict_poison`（どくびし・どくどくだま）のどちらかで付与されることを確認した。
  - README に無い関連バグを見つけた：`_resolve_move_hit` はタイプ相性が0倍でも処理を打ち切らず、`move.apply_effect` まで進んでいた。そのため 10まんボルト→じめんタイプが0ダメージなのに10%でまひし、のしかかり→ゴーストタイプでもまひしていた。でんじはは変化技なので、相性を一度も見ていなかった。
  - ダメージ計算（`damage.py`）は、0倍なら固定ダメージ技を含めて既にダメージ0を返していた。
- 実装
  - `battle.py` に `STATUS_IMMUNE_TYPE_IDS`（poison: どく7・はがね16 / burn: ほのお1 / freeze: こおり5）を追加した。
  - `Battle.can_receive_status` で、特性の判定より前にタイプ免疫を判定するようにした。かたやぶりでも貫通しない。
  - `_resolve_move_hit` で、相手に向けた技のタイプ相性が0倍なら、命中判定の前に失敗させるようにした（`result["effectiveness"] = 0.0` を返す）。
    - ダメージ技は常に判定する。変化技は `checks_type_immunity` が True の技だけを判定する。
    - みやぶる・きもったまによるゴースト無効の解除（`ignore_ghost_immunity`）はこの判定にも反映した。ダメージ計算側にあった同じ計算は削除し、変数を共用するようにした。
    - 判定の位置は、特性による無効化・でんじふゆうの後、`try_execute`・みがわり・命中判定の前。
  - `BaseMove` に `checks_type_immunity = False` を追加し、でんじは（move_105）だけ True にした。
  - README の未実装リストから該当行を削除した。
