### 実施内容
- 既存コードを調査し、対象10技が全て`effects = []`のスタブであること、`StatStages`に`accuracy`/`evasion`フィールドが無いこと、命中判定が`Battle.get_effective_hitrate`一本で行われていることを確認
- `src/battlelogic/stat_stage.py`: `StatStages`に`accuracy`/`evasion`（デフォルト0）を追加。命中率・回避率は他の能力値（基準2の段階倍率）と異なり基準3の式を使う本編仕様に合わせ、`accuracy_stage_multiplier`関数を新設
- `src/pokemon.py`: `CurrentStatus`に`is_identified: bool = False`を追加（みやぶる用の「見破られた」状態）
- `src/battlelogic/type_chart.py`: `get_move_effectiveness`に`ignore_ghost_immunity`引数を追加。ノーマル/かくとう技かつこのフラグがTrueのときは、相手のゴーストタイプを除外してタイプ相性を再計算するようにした
- `src/battlelogic/damage.py`: `calculate_damage`に同じ`ignore_ghost_immunity`引数を追加し、一撃必殺判定・通常ダメージ計算の両方で`get_move_effectiveness`に伝播させた
- `src/battlelogic/battle.py`:
  - `get_effective_hitrate`を拡張。攻撃側の`accuracy`ランクと防御側の`evasion`ランク（見破られていれば0扱い）から算出した合成ランクに`accuracy_stage_multiplier`を適用し、実効命中率を計算するように変更（シグネチャに`attacker`/`defender`を追加）
  - `switch_in`で、場を退くポケモンの`is_identified`をFalseにリセット（本編同様、対象が交代すると見破り状態が解除される仕様）
  - `perform_identify(target)`を追加（`target.current_status.is_identified = True`）
  - `use_move`内でダメージ計算・タイプ相性判定の両方に`defender.current_status.is_identified`を`ignore_ghost_immunity`として渡すよう変更
- `src/move/base_move.py`: 新しい効果種別`("identify",)`を追加し、`apply_effect`で`battle.perform_identify(defender)`を呼ぶように実装
- 対象10技（`move_016.py`えんまく、`move_034.py`かげぶんしん、`move_067.py`だくりゅう、`move_173.py`どろばくだん、`move_181.py`フラッシュ、`move_224.py`ちいさくなる、`move_237.py`みやぶる、`move_241.py`どろかけ、`move_250.py`すなかけ、`move_261.py`ミラーショット）に`effects`を設定。だくりゅう・どろばくだん・ミラーショットは30%、どろかけは100%の確率で相手の命中率-1（実際のダメージ技＋追加効果）、えんまく・フラッシュ・すなかけは100%で相手の命中率-1（変化技）、かげぶんしん・ちいさくなるは自分の回避率+1（第4世代仕様。第6世代以降の+2ではない）、みやぶるは`("identify",)`
- 動作確認: `/tmp/verify_accuracy.py`にテストスクリプトを書いて実行
  - えんまく使用で相手の`accuracy`ステージが-1になること
  - かげぶんしん使用で自分の`evasion`ステージが+1になること

  - 見破られた側のポケモンが交代すると`is_identified`がFalseに戻ること
  - だくりゅう・どろばくだん・フラッシュ・どろかけ・すなかけ・ミラーショット・ちいさくなるを実際に`use_move`で使って例外が出ないこと
