### 実施内容
- 対戦の進行（`battle.py`）
  - ターン終了時の処理を `process_end_of_turn` にまとめ、瀕死になった個体の代わりはターン終了時の処理が全部終わってから出すようにした。これで、後攻が瀕死になるとターン終了時の処理が丸ごと飛ぶバグ（1）と、ターンの途中で代わりが出るバグ（2）を直した
  - 瀕死の個体は行動しない。相手が瀕死なら、相手に向けた技は PP を消費して失敗する。おいうち・設置技で倒れた場合も、代わりはターン終了時に出す。とんぼがえり・バトンタッチは、使った側が瀕死なら交代しない
  - たいねつのやけどダメージが二重に掛かるのを直した（3）。ねむりのターン数を1〜4にした（4）。まもる系の連続成功率を1/2ずつ・下限1/8にした（5）
  - 一撃必殺技の命中率を「30＋レベル差」にし、ランク補正を受けないようにした。相手の方がレベルが高ければ失敗する（6）
  - こおり: ほのお技を受けると解ける、にほんばれ中はこおりにならない、フレアドライブで自分のこおりが解ける（7。`BaseMove.thaws_user` を追加）
  - はねやすめで、そのターンの間ひこうタイプが無くなるようにした（15。`CurrentStatus.roost_original_types`）
  - 瀕死の相手には状態異常・能力ランクの変化・ひるみが付かないようにした
- 技のデータ（`src/move/`）
  - かみなり・たつまき・うずしお・じわれが、そらをとぶ等の最中の相手に当たるようにした（9）。たつまき・うずしおは威力2倍
  - でんげきは（10）・ボルテッカー（11）・ブレイズキック（12）・こらえるの優先度（13）・接触判定（14）を直した
  - だましうち（優先度0）・ふいうち（優先度+1。失敗条件は `CurrentStatus.selected_move_this_turn` で判定）・しんそく（+1）・こおりのつぶて（+1）・がむしゃら（相手の残りHPを自分と同じにする固定ダメージ）を直した
  - クラス名の取り違えを直した（`TakeDown`→`DoubleEdge`、`Feint`→`SuckerPunch`、`SuckerPunch`→`FeintAttack`、`ZapCannon`→`ShockWave`、`Flail`→`Endeavor`、`Flail2`→`Flail`）
- ダメージ計算（`damage.py`）
  - ソーラービームがすなあらし・あられでも半分になるようにした（8）
  - 第4世代の式の順番どおりに、補正のたびに切り捨てるようにした。タイプ相性は `type_chart.get_move_effectiveness_factors` でタイプ1・2を1つずつ掛ける。いのちのたま・メトロノームは乱数の前に掛ける（`BaseItem.get_damage_multiplier_before_random` を追加）。ダメージは最低1
- 持ち物: ピントレンズのなげつけるの威力を30にした（16）
- 体重のデータ
  - PokeAPI の `pokemon.csv` は GitHub から取れた（pokeapi.co と Bulbapedia はプロキシで403）。図鑑番号1〜493の通常の姿の体重を `data/weight.csv` にした
  - `tools/build_base_stats.py` で `base_stats.json` に体重を入れるようにし、`Pokemon.weight` を追加。くさむすびの威力を体重で決めるようにした
