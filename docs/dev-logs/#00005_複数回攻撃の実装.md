  - `move/base_move.py`の`BaseMove.__init__`に`min_hits`/`max_hits`（デフォルト1/1）を追加
  - 該当5技の`move_XXX.py`から「複数回攻撃は未実装」コメントを削除し、`min_hits`/`max_hits`を設定（2-5回攻撃グループは`2,5`、固定2回攻撃グループは`2,2`）

  - `use_move`を変更し、命中判定は1回だけ行い、その後`roll_hit_count`で決めたヒット回数分だけダメージ計算・適用をループする形にした（相手が瀕死になった時点でループを打ち切る）。戻り値の`result`に`hit_count`を追加
  - 前回（#00004）に発覚した「`Struggle`（わるあがき）が`BaseMove.__init__`を経由しないため新属性を持たない」問題を踏まえ、今回は先回りして`struggle.py`にも`min_hits=1, max_hits=1`を追加しておいた
- 動作確認:
  - `roll_hit_count`を8000回試行し、2/3/4回がそれぞれ理論値37.5%に近く、4/5回がそれぞれ理論値12.5%に近いことを確認
  - にどげりが常に2回になることを確認
  - `Battle.use_move`経由でボーンラッシュを実際に撃ち、4回ヒットして合計ダメージが加算され`hit_count`も正しく記録されることを確認
