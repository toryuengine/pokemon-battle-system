### 目的
「じたばた」の正しい効果（自分の残りHP割合による威力変化）をユーザーから教えてもらい実装する。あわせて「がむしゃら」「いたみわけ」の効果について認識のズレを確認・修正する

### 実施内容
- ユーザーから「じたばたは自分の残りHPの量によって威力が変化する技」と教えてもらい、威力テーブル（残りHP割合ごとの威力）を表形式で提示された
- `BaseMove`に`has_hp_based_power`（デフォルト`False`）を追加
- `move_228.py`のクラス名を、以前の命名ミス`Struggle2`から`Flail2`に修正し、`has_hp_based_power = True`を設定。`movefactory.py`のimport・登録も更新
- `battlelogic/damage.py`に`HP_BASED_POWER_TABLE`（ユーザー提示の表通り: 68.75%以上→20, 35.42〜68.74%→40, 15.63〜35.41%→80, 9.38〜15.62%→100, 4.17〜9.37%→150, 4.16%以下→200）と`get_hp_based_power`を追加。`calculate_damage`で`has_hp_based_power`な技はこの計算値を使うように修正
- 境界値ちょうど（0.6875, 0.3542, 0.1563, 0.0938, 0.0417等）を実数のまま検証し、テーブル通りの威力が返ることを確認。`use_move`経由の実行、`main.py`のシミュレーションもエラー無しを確認
- README.mdの「要確認」リストから`move_228.py`（じたばた）を削除
- ユーザーから「がむしゃらは自分と相手のHPを同じにする技ではなかったか」と質問され、実際は「がむしゃら」(Flail, id172)はじたばたと同じ「自分の残りHP依存で威力が変わる」技であり、HPを揃える技ではないことを回答。HPを揃える技は「いたみわけ」(Pain Split, id258)であることを説明
- ユーザーから「いたみわけは相手の残りHPから自分の残りHPを引いた数値分のダメージを与える効果」という理解を提示されたが、実際の仕様は「自分と相手の現在HPを合計して2で割った平均値に、両者ともHPを揃える」（差分そのものではなく差分の半分だけ変動し、自分の方がHPが多ければ自分が減って相手が回復する等、必ずしも一方的にダメージを与えるとは限らない）ことを説明し、ユーザーに確認を求めている途中で本ログの実行を求められた
