### 目的
第4世代では、げきりん・あばれるが途中で外れたり、まもるで防がれたりすると、その時点で技の固定（あばれ状態）が解ける。ユーザーからこの仕様の指摘を受け、エンジンをそれに合わせる。これまでは「外れた・防がれた場合も固定が続く」実装で、README の「推測で決めた細かい仕様」に挙げていた。

### 実施内容
- `Battle.use_move` の最後で固定ターンを減らす処理に、技が当たらなかったとき（`result["hit"]` が False）の分岐を足した。この場合は `end_rampage` で固定だけを解き、こんらんさせない
  - 外れた・まもるで防がれた場合に加えて、タイプ相性・特性で無効にされた場合も「当たらなかった」としてまとめて同じ扱いにした
  - 最後のターンに外れた場合もこんらんしない
  - 相手が先に瀕死になっていて技が出せなかったターンは、これまでどおり手前の早期 return で抜けるので、ターンは数えず固定も続く（README にも明記した）
- README：「推測で決めた細かい仕様」から該当の項目を消し、げきりん・あばれるの説明を新しい挙動に書き換えた
- `tests/test_battle.py` にテストを足した
  - `test_rampage_ends_when_disrupted`（外れた／まもる／ゴーストタイプで無効、の3パターン）：1ターン目に当てて固定させ、2ターン目に当たらなかったら固定が解け、こんらんもしないこと
  - `test_rampage_confuses_after_last_turn`：当たり続けた場合は、これまでどおり最後のターンの後にこんらんすること
- 修正前のコードで新しいテストが失敗する（3件）ことを確かめてから、修正後に全体を実行した
