### 目的
CLAUDE.md のフェーズ1（ファクトリー本体）に着手する。`Battle factory gen4 rules.md` のうち、シングル・Lv.50/オープンレベルの挑戦の流れ（レンタル→ヒント→対戦→交換×7→次の周）を、判断をすべて Agent に問い合わせる形で動かせるところまで作る。

### 実施内容
- 調査
  - `data/pokemon.json` は136種×4セットで、実数値しか無く、種族値・努力値・性格・グループ・バリエーション番号が無かった。種族の顔ぶれ（フシギバナ〜ケッキング、伝説なし）からグループ2のリストと判断した。グループ1と伝説のポケモンは入っていない。
  - Bulbapedia はこの環境からアクセスできなかった（プロキシで403）。GitHub の raw ファイルは取得できたので、種族値は Pokémon Showdown の `data/pokedex.ts` と第5〜7世代の差分（mods）、日本語名→図鑑番号は PokeAPI の CSV を使った。
  - ダメージ計算は `LEVEL = 100` 固定だった。レベルに依存する固定ダメージ技（ナイトヘッド等）はデータに無かった。
- データ整備（ブランチ `claude/factory-data-stats`）
  - `src/nature.py` に性格の表と実数値の計算式を追加した。
  - `tools/enrich_pokemon_data.py` を作り、種族値（第4世代の値）を付け、既存の実数値から努力値と性格を逆算した。フロンティアの努力値の振り方（選んだ能力に510を均等割り）×25性格を総当たりし、全544セットで解が1通りに決まった（2能力に255ずつが519セット、3能力に170ずつが25セット）。
  - 各種族の4セットを、グループ2の1〜4番目のバリエーションとみなして `group`・`variation` を付けた。
  - `Pokemon` に `level`・`iv`・`rng` 引数を追加し、実数値を計算で出すようにした。省略時はLv.100・個体値0で、元データの実数値と一致する（テストで全セット確認）。ダメージ計算・こんらんの自傷は攻撃側のレベルを使うようにした。
- ファクトリー本体（ブランチ `claude/factory-single`）
  - エンジン: `Trainer` に `move_policy`・`replacement_policy` を追加した。`Battle.select_move` を `get_forced_move`・`get_usable_moves`・`get_move_options` に分け、選べる技が2つ以上のときだけ `move_policy` に聞く。瀕死・とんぼがえり・バトンタッチの交代先は `Battle.choose_replacement` に集約した。`Battle.turn`（経過ターン数）と `Pokemon.revealed_move_ids`（使って相手に見られた技）を追加した。
  - `src/factory/`: ルールの表（rules）、セットの絞り込み（pool）、レンタル候補・相手チームの生成（generator）、対戦前ヒント（hints）、観測（observation）、Agent のインターフェース（agent）、1戦の実行（battle_runner）、挑戦の流れ（challenge）。
  - `src/agents/random_agent.py`: ランダムに判断するベースライン。
  - `src/experiments/run_factory.py`: Agent を周回させ、平均連勝・1周クリア率・ネジキ戦の成績をシード・コミットと一緒に表示する。
  - `tests/`: pytest を導入し、実数値の計算・ルールの表・生成・ヒント・挑戦の流れ・観測の情報制限・エンジンのフックのテストを書いた（71件）。
  - README（実装状況・未実装・推測した仕様・「ポケモンのデータについて」「バトルファクトリーについて」の節）と CLAUDE.md（フェーズの状態・データ・ディレクトリ構成・Agent の節）を更新した。

### 結果
- テスト71件がすべて通った。`src/main.py` も従来どおり動いた。
- 1戦目（どちらも1周目のデータ・ランダム同士）の勝率は1500戦で0.498になり、左右で偏りが無いことを確かめた。
- `run_factory.py --agent random random-switch --runs 300 --seed 0`（Lv.50）では、random が平均連勝1.20（最大17、1周クリア率2.7%）、random-switch が0.72だった。同じシードで2回実行して同じ結果になった。
- 未解決: グループ1・伝説のデータが無く、Lv.50の1〜3周目はグループ2で代用している。相手の持ち物・特性は観測に入らない（判明を記録する仕組みが無い）。対戦エンジンの乱数は `random` モジュールのまま。
