### 目的
README の「仕組みそのものが無いもの」に残っていた、技の接触判定を実装する。あわせて、接触判定が無いために `UnimplementedAbility` のままだった特性6種（ほうし・せいでんき・ゆうばく・メロメロボディ・どくのトゲ・ほのおのからだ）と、しめりけでゆうばくを不発にする効果を実装する。

### 実施内容
- 調査
  - `move.json` には接触の情報が無い。技の性質は `BaseMove._init_extra_defaults` のデフォルト値をサブクラスで上書きする書き方になっている。
  - `Battle._resolve_move_hit` の複数回攻撃のループで、1回ごとに本体へのダメージ・みがわり・急所の特性（いかりのつぼ）を処理していた。接触特性もここで呼ぶことにした。
  - `try_apply_status` は、効果の発生元(source)が相手なら対象のみがわりで防ぐ。そのため、接触特性で攻撃した側を状態異常にする場合は、みがわりの判定を飛ばす必要があった。
  - 状態異常のタイプ無効の表（`STATUS_IMMUNE_TYPE_IDS`）は、でんきタイプのまひ無効が無く、第4世代仕様と合っていた。
- 実装
  - `BaseMove` に `makes_contact = False` を追加した。物理技のうち非接触の17技（タネばくだん・じしん・いわなだれ・ストーンエッジ・ダストシュート・すなじごく・じわれ・ボーンラッシュ・サイコカッター・だいばくはつ・なげつける・こうげきしれい・はっぱカッター・ゴッドバード・メタルバースト・マグネットボム・がんせきほう）を除く93技と、わるあがきで `True` に上書きした。93ファイルはスクリプトで一括編集した。
  - 144（クラス名 `Feint`）と184（クラス名 `SuckerPunch`）は、データ上の名前（ふいうち・だましうち）に合わせてどちらも接触技にした。
  - `BaseAbility` にフック `on_contact_received(battle, pokemon, attacker, move)` を追加した。
  - `_resolve_move_hit` で、接触技が本体にダメージを与えるたびに、受けた側の `get_ability(defender).on_contact_received` を呼ぶようにした。
    - かたやぶりの相手にも発動する。攻撃した側が既に瀕死なら呼ばない。
    - ゆうばくで攻撃した側が瀕死になったら、複数回攻撃のループを抜ける。
  - `try_apply_status` に引数 `bypass_substitute` を追加した。
  - `shared.py` に `ContactStatusAbility` と `CONTACT_EFFECT_CHANCE = 0.3` を追加した。30%で `conditions` の中からランダムに1つの状態異常をうつす。ほうし・せいでんき・どくのトゲ・ほのおのからだはこれを継承して実装した。
  - メロメロボディは、30%で既存の `perform_attract` を呼ぶようにした（性別の条件・どんかんの判定をそのまま使う）。
  - ゆうばくは、持ち主が瀕死になったときに相手の最大HPの1/4のダメージを与える。`Battle.is_damp_active`（場のどちらかが `prevents_self_destruct`）が真なら発動しない。
  - `apply_drain` で、攻撃した側が瀕死なら回復しないようにした。
    - ゆうばく（またはみちづれ）で瀕死になった直後に、ドレインパンチの吸収で復活してしまうのを防ぐため。
    - みちづれでも同じことが起きうる、もとからあった問題でもある。
  - 使われなくなった `UnimplementedAbility` クラスを `shared.py` から削除し、しめりけ（`ability_008.py`）のコメントも直した。
  - README を更新した。
    - 実装済みに追加し、特性を75種から81種にした。
    - 未実装の項目を削除した。
    - 「技の接触判定について」の節を新設した（接触技の一覧・発動条件・特性の効果の表）。
    - 「推測で決めた細かい仕様」に3項目を追記した。
    - 性別の節・特性の節を更新した。

### 結果
- テストディレクトリが無いため、検証スクリプトをスクラッチパッドに作って確認した。最終的に32ケースすべて期待どおりだった。
  - 初回は3件がNGだったが、いずれも検証スクリプト側の誤りだった。
    - 発動率を元に戻す処理で、既に1.0に書き換えた値を使っていた。
    - ゆうばくで瀕死になるかのケースで、HPの設定が足りず瀕死にならなかった。
  - 確認した内容:
    - 各特性が接触技で発動すること。じしん（非接触）・10まんボルト（特殊）では発動しないこと。
    - でんきタイプもまひになること。ほのお・はがねタイプとめんえきは無効になること。
    - かたやぶりの相手にも発動すること。攻撃側のみがわりでは防げないこと。
    - 防御側のみがわりが受けた攻撃、まもるで防がれた攻撃では発動しないこと。
    - シンクロでうつし返すこと。いえきで消されていれば発動しないこと。
    - ほうしの3種がほぼ1/3ずつになること（3000回）。くさタイプにも効くこと。
    - メロメロボディが異性にだけ効き、同性・性別不明・どんかんには効かないこと。
    - ダブルアタックで2回当たること。わるあがきが接触技として扱われること。
    - ゆうばくが1/4のダメージを与え、瀕死にならない・非接触・しめりけのときは発動しないこと。
    - ゆうばくで瀕死になった後、ドレインパンチで復活しないこと。ゆうばくとみちづれが併発すること。
    - 発動率が30%になること（5000回で0.30）。
- 回帰確認として、全544個体からランダムに選んだ1対1の対戦を2000戦回し、エラーが出ないことを確認した。
  - 半分の対戦は、接触特性を持ちうる48個体のどれかに接触特性を持たせて対戦させた。
