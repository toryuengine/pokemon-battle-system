### 目的
README の「効果はあるが、成否の条件が抜けている技」に残っていた、ねむる（168）を直す。
- 既にどく・まひ等にかかっていると、状態異常を上書きできずにHPだけ回復していた（本来は状態異常を治してからねむる）
- ねむるターン数が、他のねむりと同じ1〜3ターンのランダムだった（本来は2ターン固定）
- HPが満タン・既にねむっているときも成功していた
- ふみん・リーフガードでねむれない場合も、回復だけは行われていた（「本編と食い違っている可能性が高い箇所」に記載していたもの）

### 実施内容
- 調査
  - `move_168.py` の `Rest` は `effects = [('heal', 1.0), ('status', 'self', 'sleep', 1.0)]` で、回復とねむり付与を別々に適用していた。`try_apply_status` は既に状態異常があると上書きせず、ねむりのターン数も `random.randint(1, 3)` だった。
  - ねむりの行動判定（`can_act`）は、残りターンが0以下なら起きて行動し、そうでなければ残りターンを減らして行動不能（はやおきは2ずつ減る）。残り2を設定すれば2ターンねむって3ターン目に行動する。
- 実装
  - `Rest.try_execute` を追加し、HPが満タン・既にねむっている・ねむり状態にならない（`Battle.can_receive_status`。ふみん、にほんばれ中のリーフガード）なら失敗するようにした。ねごとで呼び出した場合は自分がねむっているので失敗する。
  - 効果を新しい `("rest",)` にまとめ、`Battle.perform_rest` で「状態異常を治す（`cure_status`。もうどくのカウンタもリセット）→ ねむり・残り `REST_SLEEP_TURNS`（=2）ターン → HP全回復」を行うようにした。こんらんは治さない。
  - README：未実装リストから削除し（節ごと削除）、「本編と食い違っている可能性が高い箇所」のふみん・リーフガードの項目も削除した。「威力・成否の条件がある技について」に仕様を追記した。

### 結果
- テストディレクトリが無いため、検証スクリプトをスクラッチパッドに作って確認した。10ケースすべて期待どおりだった。
  1. HP満タンで使う：失敗（PPは1減り、ねむらない）
  2. まひ状態・HP減少で使う：まひが治ってねむり、HP全回復、残りターン2
  3. その後の行動判定：行動不能・行動不能・行動可能（2ターンねむって3ターン目に行動）
  4. もうどく＋こんらんで使う：もうどくのカウンタが0に戻り、こんらんは残る
  5. ねむり中に使う：失敗（回復しない）
  6. ねごとからねむるを呼び出す：失敗
  7. ふみん：失敗（回復しない）
  8. にほんばれ中のリーフガード：失敗
  9. 晴れでないリーフガード：成功
  10. はやおき：1ターンねむって2ターン目に行動
