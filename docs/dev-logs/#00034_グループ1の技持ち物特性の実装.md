### 目的
グループ1（Lv.50の1〜3周目）のセットで使われるのに、まだデータに無かった技・持ち物・特性を対戦エンジンに足す。
- 技：こうそくスピン・しんぴのまもり・とびはねる
- 持ち物：あかいいと
- 特性：マジックガード・やるき

### 実施内容
- 先に README の「📦 足りないデータ」と「❌ 未実装」の該当行を、技・持ち物・特性の3つに分けた（元は「技・特性」とまとめていたが、あかいいとは持ち物）。ブランチ `readme-split-missing-data` にコミット・プッシュ済み
- 第4世代の仕様をWeb検索で確かめた（Bulbapedia等は直接開けず、検索結果の要約から判断）
  - マジックガード：わるあがきの反動は防がない。第4世代だけ、まひで動けなくなることが無く、どくびしでどくにならない。やどりぎのタネは相手も回復しない
  - しんぴのまもり：第4世代では、せいでんき等の接触で発動する特性は防げない（防げるのは第5世代から）。どくどくだまは防ぐ。既にかかっているねむけは防がない。げきりんの後のこんらんは防がない
  - こうそくスピン：しめつけ・やどりぎのタネ・まきびし・どくびし・ステルスロックを取り除く。ゴーストタイプに当たらなければ効果なし
- データ：`move.json` に 271 こうそくスピン・272 しんぴのまもり・273 とびはねる、`ability.json` に 90 マジックガード・91 やるき、`item.json` に 55 あかいいと を追加
- 技
  - こうそくスピン：新しい効果 `("rapid_spin",)` と `Battle.perform_rapid_spin`
  - しんぴのまもり：新しい効果 `("safeguard",)`、`Trainer.safeguard_turns_remaining`（5ターン、`tick_screens` で減らす）、`Battle.set_safeguard`・`is_safeguarded`。`try_apply_status` で相手からの状態異常・こんらんを防ぐ（`bypass_safeguard` 引数を追加し、接触で発動する特性は防がない）。あくび・どくびし・シンクロ・どくどくだまにも判定を足した
  - とびはねる：そらをとぶと同じ溜め＋回避状態、30%でまひ。かみなり・たつまき・スカイアッパーがとびはねる中の相手にも当たるようにした（`BOUNCE_ID`）
- 持ち物 あかいいと：`BaseItem.on_infatuated` フックを足し、`perform_attract` から呼ぶ。`DestinyKnot` は `src/item/destiny_knot.py`
- 特性
  - マジックガード：`BaseAbility.prevents_indirect_damage` と `Battle.apply_indirect_damage` を足し、どく・やけど・のろい・あくむ・しめつけ・やどりぎのタネ・天候・まきびし・ステルスロック・反動・いのちのたま・くろいヘドロ・ゆうばく・ヘドロえきのダメージをこれ経由にした。まひの行動不能とどくびしの判定にも足した
  - やるき：`StatusImmunityAbility` でねむりを無効（ふみんと同じ。ねむるも失敗する）
- テスト：`tests/test_group1_effects.py` を新規作成（31件）。`tests/test_data.py` に `FLY_ID`・`BOUNCE_ID` の名前の確認を追加
  - 1件、ゆうばくのテストでねこだましを使ったら（場に出た最初のターンでないので）失敗して落ちたため、だましうちに変えた
- 新しい技・特性・持ち物をランダムに持たせた3対3の対戦を3000回回し、例外が出ないことを確かめた
- README（実装状況の数・各節の説明・推測で決めた仕様）と CLAUDE.md（やることリストD）を更新
