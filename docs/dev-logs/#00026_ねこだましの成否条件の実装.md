### 目的
README の「効果はあるが、成否の条件が抜けている技」にあった、ねこだまし（74）を直す。
- 場に出てから最初のターンにしか成功しないようにする（これまでは、いつ使っても必ずひるませていた）

### 実施内容
- 調査
  - `move_074.py` の `FakeOut` は `effects = [('flinch', 'target', 1.0)]` だけで、成否の判定が無かった。
  - 技の成否は `BaseMove.try_execute` で判定できる（`battle.py` の `_resolve_move_hit` から、タイプ相性による無効判定の後・みがわり・命中判定の前に呼ばれ、PPは消費済み）。とっておき・きあいパンチがこれを使っている。
  - 交代時の状態リセットは `switch_in` → `clear_volatile_statuses` で行われ、瀕死後の交代・手動の交代・とんぼがえり・バトンタッチはすべてここを通る。
- 実装方針
  - 「場に出てから迎えたターン数」を数え、ターンの頭で増やすことにした。ターン終了時に数えると、とんぼがえり等でターンの途中に出た個体が、次のターンに失敗してしまうため。
  - Showdown は「場に出てから行動しようとした回数」で判定しているようだが、今回はターン数で判定した。そのため、最初のターンにまひ・ひるみ等で動けなかった場合は、次のターンには使えない。第4世代の本編でどちらが正しいかは確認できていない。
- 実装
  - `CurrentStatus` に `turns_on_field: int = 0` を追加した。
  - `Battle.start_battle` で、毎ターン頭のリセット処理の中で `turns_on_field += 1` するようにした。
  - `Battle.clear_volatile_statuses` で `turns_on_field = 0` に戻すようにした。`passed_status` には入れていないので、バトンタッチでも引き継がない。
  - `FakeOut.try_execute` を追加し、`turns_on_field == 1` のときだけ成功するようにした。
  - README：未実装リストから削除し、「威力・成否の条件がある技について」に仕様を追記した。「推測で決めた細かい仕様」に、最初のターンに動けなかった場合の扱いを追記した。

### 結果
- テストディレクトリが無いため、`Battle` のサブクラスで技・交代を台本どおりに選ばせる検証スクリプトをスクラッチパッドに作って確認した。5ケースすべて期待どおりだった。
  1. 両者が毎ターンねこだまし：1ターン目に先に動いた側だけ成功し、相手はひるんだ。2・3ターン目は両者とも失敗した
  2. 手動交代：2ターン目に交代した個体が、3ターン目に成功して4ターン目に失敗した
  3. とんぼがえり：2ターン目に交代した個体が、3ターン目に成功して4ターン目に失敗した
  4. バトンタッチ：2ターン目に交代した個体が、3ターン目に成功して4ターン目に失敗した
  5. 1ターン目にひるまされて動けなかった個体は、2ターン目に失敗した（方針どおり）
- 最初の実行では、とんぼがえり・バトンタッチのケースが検証スクリプト側のミス（1ターン目に交代してしまい、交代先が持っていない技を選ぼうとした）で止まった。台本を直して再実行した。
