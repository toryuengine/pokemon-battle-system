### 目的
ユーザーが作成した種族値の表 `data/base_stats.csv`（第4世代の全493種。図鑑番号・名前・種族値・合計・タイプ）をjson形式にして、コードから使える形にする。新しい技等が増えて未実装が出たらREADMEに書く。

### 実施内容
- CSVの調査
  - 493行、図鑑番号1〜493の重複・欠けなし。先頭にBOMあり。全行で種族値の合計がtotal列と一致
  - タイプ名はすべて `data/type.json` にある名前（フェアリー等の第6世代以降のタイプは無い）
  - 第6世代以降に種族値が変わった種族（ライチュウ・フーディン・ピジョット・バタフリー等）が第4世代の値になっていることを確認
  - ファクトリーの150種について、既存の `data/species.json` の図鑑番号・種族値、周ごとのファイルのタイプと突き合わせ、全種一致した
- `tools/build_base_stats.py` を新規作成。CSV → `data/base_stats.json`（キーは図鑑番号。種族名・タイプID（単タイプは `type2: null`）・種族値）。合計値・図鑑番号の重複・1〜493がそろっているかを確かめてから書き出す
- 種族値の出どころを `base_stats.json` に一本化
  - `data/species.json` から `base_stats` を削除（図鑑番号・メスになる確率・伝説かだけ残す）
  - `readpokemondata.py` に `load_base_stats_data()` を追加し、`_build_pokemon_data()` で図鑑番号から種族値を引くようにした。その際、`base_stats.json` と周ごとのファイルで種族名・タイプが一致することをassertで確かめる
- テスト：`tests/test_data.py` に、493種そろっていること・第4世代の値になっていること・ファクトリー外の種族（343種）も入っていることのテストを追加
- 新しい技・特性・持ち物はこのデータでは増えていない（CSVは種族値とタイプだけ）。既存の `test_data.py` の「全技・特性・持ち物にクラスがある」テストも通っている
- README（データの説明、未実装に「ファクトリー外の343種は特性・性別比率・伝説か・体重のデータが無い」を追記）と CLAUDE.md の「3.5 データ」を更新
