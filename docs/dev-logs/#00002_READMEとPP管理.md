- PP管理を実装:
  - `move/base_move.py`の`BaseMove.__init__`に`current_pp`（残りPP、初期値は`pp`と同じ）を追加

  - `battlelogic/battle.py`の`select_move`を、`current_pp > 0`の技だけから選ぶように変更し、候補が無ければ`Struggle()`を返すよう修正（列内包表記ではなくfor文で書くよう、以前ユーザーから指示された方針に合わせた）
  - `use_move`の冒頭で、命中・失敗に関わらず技を使った時点で`current_pp`を1減らすように追加
  - `apply_max_hp_recoil`メソッドを`Battle`に追加
- 動作確認として、フレアドライブ持ちのポケモンで反動により先にHP0になるケースと、反動技を持たないポケモン（メガニウム）でPPがちょうど尽きてわるあがきに切り替わるケースの両方を手動スクリプトで検証。300試合のランダム対戦テストと`main.py`の1万戦シミュレーションもエラー無く完走することを確認
