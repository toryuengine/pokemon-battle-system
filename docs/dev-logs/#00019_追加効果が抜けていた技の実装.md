### 目的
READMEの「追加効果が抜けている技（`effects`が空で、ただのダメージ技として動く）」に挙がっていた9技に、第4世代仕様の追加効果を実装する。実装前にユーザーから効果の内容の説明を求められたので、先に説明してから実装した。

### 実施内容
- 対象技のコード・`data/move.json`・既存の仕組み（`effects`の形式、`high_crit`、`hits_during_charge_move_ids`、`battle.py`の命中判定）を調査し、各技の効果と実装方針をユーザーに説明した
  - 調査中に、かわらわり（77）は`battle.py`の`BRICK_BREAK_ID`で壁破壊が既に実装済みで、READMEの記述が古いだけだと判明した
  - すてみタックルのクラス名が`TakeDown`（とっしんの英名）になっている点も伝えた（動作に影響しないので変更していない）
- ユーザーの了承後、8技の技クラスを修正した
  - エアスラッシュ（15）: `('flinch', 'target', 0.3)`
  - ゴッドバード（206）: `('flinch', 'target', 0.3)`と`high_crit = True`
  - ストーンエッジ（63）: `high_crit = True`
  - すてみタックル（138）: `('recoil', 1/3)`
  - だいちのちから（68）・ラスターカノン（83）・むしのさざめき（248）: `('stat', 'target', 'spdef', -1, 0.1)`
  - スカイアッパー（126）: `hits_during_charge_move_ids = (FLY_ID,)`（そらをとぶ=141）。威力2倍はじしん・なみのりが自分の`get_power`で持っている処理なので、スカイアッパーでは上書きせず、威力は85のまま
- テストスイートが無いので、スクラッチパッドにシミュレーション用の確認スクリプトを書いて検証した
  - 最初はモジュールのパス・属性名（`current_hp`は`current_status`の中、ランクは`battle.get_stages()`）を間違えて何度かエラーになり、修正してから実行した
- `main.py`の10000戦シミュレーションもエラーなく完走することを確認した
- READMEから「追加効果が抜けている技」の節を削除し、「追加効果を後から実装した技について」の節を追加した（かわらわりが`BRICK_BREAK_ID`で処理済みであることも明記）
