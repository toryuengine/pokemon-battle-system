### 実施内容
- 事前の調査（ユーザーとの質疑）
  - 「型が1つしかなくなった」という質問 → 旧形式の `pokemon_0.json`（1周目）は1種族1セットだが、周が進むとセットが増え、全体では150種×4セットあることを説明

  - 最初にコミットされた `data/pokemon.json` は技・持ち物IDが旧 `move.json`・`item.json` と合っていない（例：フシギバナの2番目のセットが、かえんほうしゃ等に化ける）ことを確認し、同じ回の実行で作った `move.json`・`item.json`・`ability.json` が必要と伝えた
  - `data2/` を名前ベースで旧データと照合：全600セット（技・持ち物・性格・努力値）、種族ごとの特性、技の性能、各周のセット（`round.json` の `groups` で抽出）がすべて一致。IDは技271個中261個、持ち物55個中51個が変化、特性は変化なし
- 変更前に、旧コードで3体×3体の対戦20000戦（8周目のプール、シード固定、個体値0/12/31、交代確率0.2）を記録する回帰チェックを用意した
- データ
  - `data/pokemon_0〜8.json` と旧 `data/move.json`・`data/item.json` を `delete/` に移動
  - `data2/move.json`・`data2/item.json` を `data/` に置いた。`data2/` の他の4ファイル（`pokemon.json`・`round.json`・`ability.json`・`pokemon_name.json`）は `data/` のものとバイト単位で同じだったので、`data/` 側をそのまま使う
